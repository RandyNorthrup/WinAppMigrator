# Plan: languages and accessibility (0.7.0)

Owner's request, 2026-11-15, after issue #2 came from a user in Italy: make WinAppMigrator fully internationalized,
accessible, and WCAG compliant, and release it in the most-used languages, all machine-translated since there are no
native-speaking contributors yet, covering whatever else this needs. Decisions he made the same day:

- **Right-to-left now.** Arabic, Persian, Urdu, and Hebrew ship in this release, with mirrored windows and mixed-direction
  text, rather than waiting for a later one.
- **About 20 most-used languages**, plus the four right-to-left ones: 24 with English.
- **The website** gets a translated landing page and three key guide pages per language (Getting Started, Installing on the
  New PC, Troubleshooting). The rest of the guide stays English, and says so.

This plan is the canonical plan for this work unit. [docs/PLAN.md](../PLAN.md) stays the product plan and links here. The
ledger at the end owns requirements, acceptance, tasks, status, and evidence; nothing below repeats their states.

## Decisions

- **Fluent** (`fluent-bundle`) for catalogs: one `.ftl` file per language. It handles each language's plural rules (Polish and
  Russian have three or four forms, Arabic six), and translators can reorder a sentence's parts. Catalogs are embedded
  compressed, because every installer carries every language: the PC it runs on may speak any of them.
- **One new crate, `winappmigrator-i18n`**, used by core, the shared UI crate, the app, the installer, and the client. It holds
  the catalogs, picks the language, formats numbers and sizes, and makes the two test languages: a pseudo-English with accents
  and 40% longer text, which shows any text left untranslated or cut off, and a pseudo right-to-left one. It builds for the
  Windows 7 client's target too.
- **Which language:** the one chosen in the app, else the first of Windows' preferred display languages that ships, else
  English. Windows' list is read from the registry (`HKCU\Control Panel\International\User Profile`), because the workspace
  bans `unsafe` and the API needs it. A language that ships only as a regional variant still matches (`pt-PT` gets `pt-BR`).
- **An installer speaks the new PC's language,** not the one it was built in. What a package records for later display, its
  warnings, is kept as a code with arguments as well as English, and is translated where it is shown. A package from an older
  version shows its English as before.
- **Logs stay usable for support:** codes, paths, and English where code writes them; a message a person saw may be logged in
  their language.
- **Right-to-left** is built into the shared UI crate: a direction for the window, layouts that mirror, painted icons that
  flip where direction means something (chevrons, progress), and text laid out by the Unicode bidirectional algorithm
  (`unicode-bidi`), each run shaped in its own direction by egui's own shaper. Paths, versions, and other code-like text stay
  left to right inside a right-to-left sentence. Text boxes for paths stay left to right.
- **The Windows 7 client** prints in Windows' display language. The Windows 7 console cannot join or reorder Arabic or Hebrew
  letters, so in a right-to-left language it prints English, with one line saying why. `--lang` chooses any language.
- **Formats:** decimal and grouping separators from the user's own Windows settings (`sDecimal`, `sThousand`), and from the
  language otherwise; unit names (`MB`, `Mo`, `МБ`) are translated.
- **Accessibility target:** WCAG 2.2 level AA, applied to desktop software as [WCAG2ICT](https://www.w3.org/TR/wcag2ict-22/)
  describes, which is also what EN 301 549 (the European standard behind the European Accessibility Act) asks of software.
  The website is held to WCAG 2.2 AA directly. Conformance is self-assessed and published as an Accessibility Conformance
  Report; nothing here is a third-party certification, and the report says so.
- **Windows settings honored:** contrast themes (system colors replace the palette), the Text size setting (text scales), and
  Animation effects off (nothing animates).
- **Automated checks:** Axe.Windows (Microsoft's rules for UI Automation) on the real windows in CI, axe-core on every page of
  the website, and headless UI tests that walk each screen's accessibility tree for names, roles, and target sizes.
- **Machine translation** is done in this repository by coding agents, with no paid service and no credentials: one
  agent per language translates every catalog from the English and records its term choices in `locales/<tag>/terms.md`,
  then a second, independent agent per language back-translates a sample of at least 60 messages, fixes what it finds,
  and writes `reports/i18n-a11y/review/<tag>.md`. `scripts/ftl-tool.py` checks each language as the Rust test does, and
  also for missing plural forms and text left in English. The app says the translation is by machine and links to a
  "Translation problem" issue form.
- **Accessibility checks** are test-only code (`crates/winappmigrator-ui/src/checks.rs`), included by path in the app's
  and the installer's tests, so no shipped crate depends on egui_kittest. Axe.Windows runs on the real windows in CI.

## Not in this release

- Human-reviewed translations: invited through the issue form and `docs/TRANSLATING.md`.
- Translating the rest of the guide (20 pages) and the changelog.
- Locale-aware sorting of the app list (ICU collation is too large for the installer); the list sorts by Unicode letters,
  ignoring case.
- Right-to-left text typed into the search box displays in the order typed; it still searches correctly.

## Risks

- **Windows tools speaking another language.** Core runs `sc.exe`, `netsh`, `icacls`, `whoami`, `robocopy`, `schtasks`, and
  PowerShell, and reads them by SID, state number, and exit code. Checked on testpc1 with Windows' Italian language pack
  and an account whose Windows speaks Italian (Microsoft's Italian evaluation media needs a registration): install,
  uninstall, and a failed install of three real apps, `reports/i18n-a11y/localized-windows.md`. Not covered: built-in
  account names on a Windows installed in Italian, which the code never reads by name.
- **Text that grows.** German and Russian run 30 to 40% longer than English; the pseudo language finds what gets cut off.
- **Size.** Every installer carries every catalog; compressed, the target is under 2 MB added to the stub.
