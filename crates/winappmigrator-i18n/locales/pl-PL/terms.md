# pl-PL terms

Polish as Windows 11 writes it. The reader is addressed as Windows does in Polish: second person singular, with
imperatives for actions (Zamknij, Wybierz, Uruchom ponownie) and "Czy chcesz…" for questions. Personal pronouns are
avoided; where one is needed, the reflexive "swój" is used. Sentence case everywhere. Quotes are „…”.
