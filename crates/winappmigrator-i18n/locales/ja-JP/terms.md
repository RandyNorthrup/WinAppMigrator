# 日本語 (ja-JP) の用語

Microsoft の日本語 Windows 11 の用語と表記に合わせています。文は です/ます 体、ボタンやラベルは簡潔な名詞形、引用は「」、句読点は全角（。、：（））、全角文字と半角英数字の間には半角スペースを入れます。
