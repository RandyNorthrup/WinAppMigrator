# Türkçe terimler (tr-TR)

Okura Windows 11'in Türkçesi gibi "siz" diye seslenilir: "seçin", "yazın", "bilgisayarınız". Düğmeler, başlıklar ve
etiketler cümle düzeninde büyük harfle yazılır ("Yükleyici oluştur"); Windows araçlarının adları Windows'taki gibi kalır
("Dosya Gezgini", "Görev Zamanlayıcı"). Bir yer tutucunun sonuna ek gelmez: ek, ardından gelen bir isme eklenir
("{ $path } klasörü", "{ $drive } sürücüsü", "{ $name } uygulaması") ya da yer tutucu iki noktadan sonra gelir.
