# Review: Simplified Chinese (zh-CN)

Reviewer: independent machine pass, 2026-11-15. Translator's form of address: 你, with plain imperatives ("请选择…",
"请重试") and no 您; kept, because that is how Windows 10 and 11 address the reader in Simplified Chinese (UAC's
"你要允许此应用对你的设备进行更改吗？", Settings' "你的信息"). The translator's other house rules are also Windows'
and were kept: 帐户 and 撤消 (Microsoft's spellings), full-width punctuation in Chinese text, a space between Chinese and
Latin words, digits and placeholders, and half-width parentheses only round Latin-only content ("警告 (3)",
"(AppData)", "(UTC)").

## Brought up to date

30 messages checked against the current English. 22 needed new words, 8 already said what English says.

Changed:

- `app-scan-failed`: the reason now follows a colon, not a full stop ("无法查看此应用：{ $error }").
- `app-footprint-licenses-still-go`, `core-footprint-licenses-left-out`, `core-review-note-licenses`,
  `core-secret-why-license-option-off`, `core-warning-scan-license-data`: "the License option" (“许可证”选项) is now
  “许可证和激活数据”选项, the same words as `app-option-license`.
- `core-warning-build-recorded-folder-left-out`, `core-warning-build-near-part-left-out` `[unreadable]`: was "它无法读取"
  (a read error); now the safety rule: "它的路径会离开该驱动器或经过链接，因此无法安全读取".
- `core-review-com-support-detail`: each count now sits beside its own kind, as in English: "其类型库（{ $libraries } 项）、
  接口（{ $interfaces } 项）和 AppID（{ $app_ids } 项）的设置，与其类配套使用".
- `core-review-start-boot`, `-system`, `-automatic`, `-delayed`, `-manual`, `-disabled`, `-unknown` (added): each
  carries its own verb, "随 Windows 启动，先于其他任何内容", "在 Windows 启动过程中启动", "在此电脑每次启动时启动",
  "在此电脑每次启动后不久启动", "仅在有程序请求时启动", "从不启动，因为它已被禁用", "以 Windows 未说明的方式启动", so that
  the sentences they fill read correctly. Their frames changed with them: `core-review-service-detail` `[other]` and
  `core-review-driver-detail-starts` were "…，启动方式为 { $start }" (which would have read "the start mode is each time this
  PC starts"), now "…，{ $start }". The wording matches the existing `[automatic]`, `[delayed]`, `[manual]` and
  `[disabled]` variants.
- `core-review-network-domain`, `-private`, `-public` (added): 域, 专用, 公用, as the Profile column of Windows Defender
  Firewall names them. Their frame in `core-review-firewall-detail` changed from "适用于以下网络：{ $networks }" to
  "适用于{ $networks }网络", so it reads "适用于专用、公用网络".
- `installer-license-detail`: was "激活和许可证文件及注册表项" (registry keys); now "激活和许可证文件，以及保存许可证的注册表值".
- `installer-no-programdata`, `installer-cli-no-programdata`: was "因此无法撤消安装" (so the install could not be undone);
  now "因此未安装任何内容：安装会将用于撤消它的记录保存在该文件夹中".

Already right: `client-builder-done`, `client-wrong-code`, `client-pair-failed` (另一台电脑 needs no capital),
`core-rollback-setting-put-back`, `core-rollback-list-entries-removed`, `core-rollback-list-entries-not-removed`,
`core-rollback-firewall-removed` (Chinese had no stray capital), `ui-disclosure` (already present: "已展开" / "已折叠", as
Narrator says it).

Comments in all nine files were brought in line with the current English by the checker's `merge` (comments only; no
message text changed by it).

## Other fixes

- `core-footprint-drivers-left-out`: "无法转交" (cannot be handed over) is now "无法再分发" (cannot be redistributed), the word
  `core-warning-build-driver-detected` and `core-service-driver-from-vendor` already use for the same thing.
- `core-policy-firewall-name`, `core-policy-firewall-description`: "无法转交" is now "无法原样沿用" (cannot be carried over as
  it is).
- `core-archive-changed-while-copied`: "在被追加到存根之后时" was ungrammatical; now "将程序包追加到存根时，程序包发生了更改".
- `core-warning-build-programs-not-inspected`: "因为程序数量太多或太大" (the number is too many or too big) is now
  "因为程序太多或体积太大" (too many programs, or too large).
- `core-source-nsis`: "卸载程序签名" read as a digital signature; the English means a recognisable byte pattern, so it is now
  "卸载程序特征".
- `core-review-account-no-desktop`: "将提供给" is now "将归属于", as in `core-review-account-signed-in`.
- `terms.md`: added rows for the firewall profiles (域，专用，公用) and for "redistribute, pass on" (再分发).

## Open questions

- Firewall profiles: 域 / 专用 / 公用 are the words in the Profile column of Windows Defender Firewall with Advanced
  Security; the sentence adds 网络 ("适用于专用、公用网络"). Windows Security shows 域网络 / 专用网络 / 公用网络. A native
  speaker should confirm this reads as Windows does.
- Service and driver start words are descriptive, as the English is, not the Services console's 自动 / 自动(延迟启动) / 手动 /
  禁用 or the driver start types 引导 / 系统. Check that "随 Windows 启动，先于其他任何内容" (boot) and "在 Windows 启动过程中启动"
  (system) are natural.
- "Loads { $file } into Windows itself" is "加载到 Windows 内核中" (into the Windows kernel), which is an interpretation.
- The Arch column is 架构, and 架构 is also the word for a manifest schema (清单架构); the sort tooltip and messages use
  体系结构. Clear in context, but a native speaker may prefer another column word (such as 平台).
- "管理员命令提示符" (`installer-window-failed-without-one`, `uninstaller-window-failed-quiet`) is common usage; Windows itself
  says "命令提示符(管理员)" or "以管理员身份运行".
