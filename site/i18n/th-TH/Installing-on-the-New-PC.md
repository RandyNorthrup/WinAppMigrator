# การติดตั้งบนพีซีเครื่องใหม่

ตัวติดตั้งเป็นหน้าต่างเดียว ตัวติดตั้งจะตรวจสอบตัวเอง แสดงตำแหน่งที่จะติดตั้งและทุกสิ่งที่จะตั้งค่า และจะติดตั้งเมื่อคุณคลิก **ติดตั้ง** เท่านั้น หน้านี้อธิบายหน้าต่างตั้งแต่บนลงล่าง โดยใช้คำที่แสดงบนหน้าจอ

## ก่อนเริ่มต้น

- **คัดลอกตัวติดตั้งทั้งหมด** หากการสร้างให้ไฟล์ `.wamdata` มาพร้อมกับไฟล์ `.exe` ให้คัดลอกทั้งสองไฟล์ไว้ในโฟลเดอร์เดียวกัน และคงชื่อไฟล์ไว้ตามเดิม โปรดดู[แอปขนาดใหญ่](Big-Apps)
- **เรียกใช้เฉพาะตัวติดตั้งที่คุณเชื่อถือ** ตัวติดตั้งทำงานด้วย[สิทธิ์ของผู้ดูแลระบบ](Glossary#administrator-rights)เต็มรูปแบบ โปรดปฏิบัติต่อตัวติดตั้งเหมือนโปรแกรมอื่นๆ: เรียกใช้เฉพาะเมื่อคุณสร้างเอง หรือได้รับจากผู้ที่คุณเชื่อถือ โปรดดู[ความเป็นส่วนตัวและความปลอดภัย](Privacy-and-Security)
- **คุณต้องมีสิทธิ์ของผู้ดูแลระบบ** บนพีซีเครื่องนี้ และต้องมี [Direct3D 12](Glossary#direct3d-12) สำหรับหน้าต่าง หากไม่มี Direct3D 12 คุณยังคงติดตั้งจากพร้อมท์คำสั่งได้ โปรดดู[บรรทัดคำสั่ง](Command-Line)

<a id="open-it"></a>

## เปิดตัวติดตั้ง

ดับเบิลคลิกตัวติดตั้ง Windows จะแสดง[ข้อความแจ้ง UAC](Glossary#uac-prompt) ตัวติดตั้งจะไม่ได้ลงนาม เว้นแต่ผู้สร้างจะลงนามเอง ข้อความแจ้งจึงมักแสดง **ผู้เผยแพร่ที่ไม่รู้จัก** ซึ่งเป็นเรื่องปกติ โปรดดู[ความเป็นส่วนตัวและความปลอดภัย](Privacy-and-Security#signing)

หน้าต่าง “ตัวติดตั้ง WinAppMigrator” “ติดตั้งแอปพลิเคชันที่เก็บมาจากพีซีเครื่องอื่นอีกครั้ง” จะเปิดขึ้นทันที ไม่ว่าตัวติดตั้งจะใหญ่เพียงใด หน้าต่างจะแสดง “กำลังตรวจสอบตัวติดตั้ง…” ระหว่างที่ตรวจสอบ[แฮช](Glossary#hash)ของแพคเกจทั้งหมด ซึ่งต้องอ่านทั้งแพคเกจ ตัวติดตั้งขนาดใหญ่จึงใช้เวลาสักครู่ ตั้งแต่ตอนนี้ ตัวติดตั้งจะเปิดไฟล์ของตัวเองค้างไว้ รวมถึงไฟล์ข้อมูลหากมี จึงไม่สามารถเปลี่ยนแปลงหรือสลับไฟล์ใดได้ระหว่างที่หน้าต่างเปิดอยู่

การตรวจสอบอาจหยุดที่ขั้นตอนนี้ พร้อมข้อความสีแดง ข้อความที่พบบ่อยได้แก่:

- ตัวติดตั้งเสียหายหรือถูกเปลี่ยนแปลงหลังจากสร้าง: โปรดคัดลอกอีกครั้งจากที่ที่สร้างไว้
- ไฟล์ข้อมูลหายไป หรือไม่ใช่ไฟล์ที่ถูกต้อง: โปรดคัดลอกทั้งสองไฟล์อีกครั้ง ไว้ในโฟลเดอร์เดียวกัน
- “ไม่สามารถใช้แพคเกจของตัวติดตั้งนี้ บนพีซีเครื่องนี้ได้” เช่น เนื่องจากโปรแกรมของแอปสร้างขึ้นสำหรับโปรเซสเซอร์ชนิดอื่น หรือต้องใช้ Windows รุ่นที่ใหม่กว่า ยังไม่มีการเปลี่ยนแปลงสิ่งใด

ข้อความทั้งหมดนี้อธิบายไว้ใน[การแก้ไขปัญหา](Troubleshooting#installing)

เมื่อผ่านการตรวจสอบ ชื่อหน้าต่างจะเปลี่ยนเป็น “ติดตั้ง” ตามด้วยชื่อแอป

<a id="its-language"></a>

### ภาษาของตัวติดตั้ง

ตัวติดตั้งจะใช้ภาษาของพีซีที่เรียกใช้ ไม่ใช่ภาษาของพีซีที่สร้างตัวติดตั้ง: ใช้ภาษาที่ใช้แสดงของ Windows หากเป็นหนึ่งใน 24 ภาษาที่ WinAppMigrator มี มิฉะนั้นจะใช้ภาษาอังกฤษ **ภาษา** ที่มุมขวาบนใช้เปลี่ยนภาษาสำหรับการเรียกใช้ครั้งนี้ สิ่งที่แสดงเกี่ยวกับแอป รวมถึงหมายเหตุที่แอปเขียนไว้ตอนสร้างตัวติดตั้ง จะแสดงเป็นภาษานั้นด้วย ตัวติดตั้งที่สร้างด้วย WinAppMigrator 0.6 หรือเก่ากว่า จะแสดงหมายเหตุเหล่านั้นเป็นภาษาอังกฤษตามที่เขียนไว้ [การติดตั้งแบบเงียบจากบรรทัดคำสั่ง](Command-Line) จะตอบเป็นภาษาอังกฤษเสมอ เพื่อให้สคริปต์อ่านได้

<a id="the-app-and-where-it-goes"></a>

## แอปและตำแหน่งที่จะติดตั้ง

การ์ดแรกแสดงชื่อแอป โดยมีผู้เผยแพร่และเวอร์ชันอยู่ด้านล่าง เช่น “Fabrikam Inc. · 1.7.3” จากนั้นจะมี:

| แถว | สิ่งที่แสดง |
| --- | --- |
| **เก็บมาจาก** | ชื่อของพีซีที่แอปมา แถวนี้จะแสดงเฉพาะเมื่อตัวติดตั้งสร้างขึ้นโดยเปิดตัวเลือก **ข้อมูลผู้ใช้** ไว้ |
| **ตัวติดตั้ง** | ไฟล์ตัวติดตั้งนี้[ลงนาม](Glossary#signature)หรือไม่: “กำลังตรวจสอบลายเซ็น…” จากนั้นเป็น “ไม่ได้ลงนาม: ไม่ทราบผู้เผยแพร่” หรือ “ลงนามโดย” ตามด้วยชื่อผู้ลงนาม ลายเซ็นที่ไม่ผ่านการตรวจสอบจะแสดงข้อความสีแดงแทน: “ลายเซ็นของตัวติดตั้งนี้ไม่ถูกต้อง” พร้อมเหตุผลของ Windows และ “ตัวติดตั้งอาจถูกเปลี่ยนแปลงหลังจากลงนาม” |
| **ตำแหน่งที่ติดตั้ง** | โฟลเดอร์ที่แอปจะติดตั้งลงไป พร้อมปุ่ม **เรียกดู** สำหรับเลือกโฟลเดอร์ ค่าเริ่มต้นคือโฟลเดอร์ที่แอปเคยอยู่บนพีซีเครื่องเก่า แอปจาก Windows แบบ 32 บิตจะเริ่มต้นที่ `Program Files (x86)` แทน ซึ่งเป็นที่ที่ Windows 64 บิตเก็บแอป 32 บิต หากใช้โฟลเดอร์นั้นที่นี่ไม่ได้ ประกาศสีแดงด้านล่างจะบอกเหตุผล |
| **พื้นที่ที่ต้องใช้** | พื้นที่ที่การติดตั้งต้องใช้บนไดรฟ์นั้น และพื้นที่ว่างที่มี เช่น “สูงสุด 824.0 MB บน C: (ว่าง 356.0 GB)” ตัวเลขนี้นับรวมแพคเกจที่แตกไฟล์แล้ว และไฟล์ของแอป |

ชื่อผู้เผยแพร่ในบรรทัดแรกมาจากแพคเกจ ซึ่งใครก็เขียนได้ แถว **ตัวติดตั้ง** มาจาก Windows และเป็นแถวที่ควรเชื่อถือ

<a id="when-the-location-cannot-be-used"></a>

### เมื่อใช้ตำแหน่งนั้นไม่ได้

หากใช้โฟลเดอร์ใน **ตำแหน่งที่ติดตั้ง** ไม่ได้ ประกาศสีแดงด้านล่างจะบอกเหตุผล **ติดตั้ง** และ **แสดงตัวอย่างการเปลี่ยนแปลง** จะเป็นสีเทาจนกว่าคุณจะเลือกโฟลเดอร์อื่น และบรรทัดข้างปุ่มจะแสดงว่า “ติดตั้ง” และ “แสดงตัวอย่างการเปลี่ยนแปลง” จะใช้ไม่ได้ จนกว่าจะสามารถใช้ตำแหน่งที่ติดตั้งได้

สาเหตุที่พบบ่อยที่สุดคือโฟลเดอร์มีไฟล์อยู่แล้ว โฟลเดอร์ที่มีไฟล์อยู่จะใช้ได้ก็ต่อเมื่อการติดตั้งครั้งก่อนจาก WinAppMigrator เป็นผู้วางไฟล์เหล่านั้นไว้ เพื่อไม่ให้ไฟล์ของแอปอื่นถูกแทนที่เลย:

| ประกาศ | ความหมาย | สิ่งที่ควรทำ |
| --- | --- | --- |
| ชื่อแอป ตามด้วย “ติดตั้งอยู่ในโฟลเดอร์นี้แล้ว จึงไม่สามารถติดตั้งสำเนานี้ที่นี่ได้” | แอปนี้ติดตั้งอยู่บนพีซีเครื่องนี้แล้ว ซึ่งมักติดตั้งโดยตัวติดตั้งของแอปเอง: โปรแกรมหลักของแอปอยู่ในโฟลเดอร์นั้น หรือรายการแอปที่ติดตั้งของ Windows ระบุว่าแอปอยู่ที่นั่น กรณีนี้เกิดกับแอปที่พีซีหลายเครื่องมีอยู่แล้ว เช่น เว็บเบราว์เซอร์ โปรแกรมเล่นสื่อ หรือ Office | ถอนการติดตั้งสำเนาบนพีซีเครื่องนี้ก่อน ในการตั้งค่า Windows ภายใต้ **แอป** แล้วเปิดตัวติดตั้งอีกครั้ง หรือพิมพ์โฟลเดอร์ใหม่ที่ว่างเปล่าลงใน **ตำแหน่งที่ติดตั้ง** เพื่อติดตั้งสำเนานี้ไว้ข้างกัน |
| ชื่อของแอปอื่น ตามด้วย “ติดตั้งอยู่ในโฟลเดอร์นี้” และแจ้งว่า “จึงไม่สามารถติดตั้ง” แอปนี้ “ที่นี่ได้” | รายการแอปที่ติดตั้งของ Windows ระบุว่ามีแอปอื่นอยู่ในโฟลเดอร์นั้น เช่น Office รุ่นอื่น | พิมพ์โฟลเดอร์ใหม่ที่ว่างเปล่าลงใน **ตำแหน่งที่ติดตั้ง** หรือหากคุณไม่ต้องการแอปอื่นนั้นแล้ว ให้ถอนการติดตั้งก่อน ในการตั้งค่า Windows ภายใต้ **แอป** แล้วเปิดตัวติดตั้งอีกครั้ง |
| “โฟลเดอร์นี้มีไฟล์ที่ไม่ได้ติดตั้งโดย WinAppMigrator อยู่แล้ว” | มีสิ่งอื่นอยู่ในโฟลเดอร์ และไม่มีแอปที่ติดตั้งใดระบุไว้ที่นั่น ไฟล์เหล่านั้นอาจเป็นของแอปอื่น | พิมพ์โฟลเดอร์ใหม่ที่ว่างเปล่าลงใน **ตำแหน่งที่ติดตั้ง** หากไฟล์เหล่านั้นหลงเหลือจากแอปที่คุณถอนการติดตั้งไปแล้ว คุณสามารถลบโฟลเดอร์นั้น แล้วเปิดตัวติดตั้งอีกครั้ง |

สำหรับเหตุผลอื่นๆ ประกาศจะแสดง “ไม่สามารถใช้โฟลเดอร์นี้ได้:” ตามด้วยเหตุผล และ “โปรดใส่โฟลเดอร์อื่นด้านบน” เหตุผลมีดังนี้:

| เหตุผลที่แสดงบนหน้าจอ | สิ่งที่ควรทำ |
| --- | --- |
| “ต้องเป็นเส้นทางแบบเต็ม” | พิมพ์เส้นทางที่ขึ้นต้นด้วยอักษรระบุไดรฟ์ เช่น `C:\Program Files\Fabrikam Data Sync` |
| “ต้องไม่ใช่ทั้งไดรฟ์” | ใช้โฟลเดอร์บนไดรฟ์ ไม่ใช่ตัวไดรฟ์เอง |
| “ต้องไม่ใช่โฟลเดอร์ Windows” | เลือกโฟลเดอร์ที่อยู่นอก `C:\Windows` |
| “มีสิ่งอื่นอยู่ร่วมกันในโฟลเดอร์นี้ แอปจึงต้องใช้โฟลเดอร์ย่อยภายในโฟลเดอร์นี้” | เพิ่มโฟลเดอร์สำหรับแอป เช่น `C:\Program Files\Fabrikam Data Sync` แทน `C:\Program Files` |
| “เป็นโฟลเดอร์ที่เป็นของ Windows หรือเป็นโฟลเดอร์ ที่สิ่งที่อยู่ภายในจะทำงานหรือโหลดได้เอง” | เลือกโฟลเดอร์ธรรมดา ตัวอย่างเช่น โฟลเดอร์ Startup จะถูกปฏิเสธ |
| “ต้องเป็นเส้นทางธรรมดาบนไดรฟ์ของพีซีเครื่องนี้” | [โฟลเดอร์ที่แชร์บนเครือข่าย](Glossary#network-share)จะถูกปฏิเสธ รวมถึงชื่อที่ Windows จะอ่านเป็นอย่างอื่นด้วย |
| แจ้งว่าโฟลเดอร์ “เป็นลิงก์ที่ชี้ไปยังที่อื่น และผู้อื่นอาจเปลี่ยนปลายทางของลิงก์ได้” | ใช้โฟลเดอร์ที่[ลิงก์](Glossary#link)ชี้ไป |
| “เป็นตำแหน่งที่การติดตั้งเก็บบันทึกไว้” | เลือกโฟลเดอร์ที่อยู่นอก `%ProgramData%\WinAppMigrator` |

หากโฟลเดอร์มีไฟล์อยู่ และมีบันทึกการติดตั้งครั้งก่อนของโปรเจกต์นี้อยู่ที่นั่น **จริง** ตัวติดตั้งจะใช้โฟลเดอร์นั้น และเตือนว่า: “โฟลเดอร์นี้มีไฟล์อยู่แล้ว ไฟล์ที่มีชื่อเดียวกันจะถูกแทนที่ และจะกลับคืนมาหากคุณถอนการติดตั้ง”

เมื่อยอมรับโฟลเดอร์แล้ว หน้าต่างจะแทนที่ไฟล์ ค่ารีจิสทรี บริการ งาน ทางลัด หรือตัวแปรที่มีชื่อเดียวกัน เช่นเดียวกับที่ `--force` ทำใน[บรรทัดคำสั่ง](Command-Line#what---force-does) สิ่งที่เป็นของแอปอื่นอยู่แล้ว เช่น บริการหรือชนิดไฟล์ของแอปนั้น จะยังคงเป็นของแอปนั้น

หากไดรฟ์ดูเหมือนมีพื้นที่ไม่พอ หมายเหตุสีเหลืองอำพันจะแสดง “พื้นที่ที่นี่อาจไม่เพียงพอ” และพื้นที่ที่ต้องใช้ แพคเกจสามารถแตกไฟล์บนไดรฟ์อื่นได้ แต่ไฟล์ของแอปยังคงต้องมีพื้นที่เพียงพอบนไดรฟ์นี้ การติดตั้งจะตรวจสอบพื้นที่อีกครั้งก่อนเริ่ม

<a id="an-earlier-install-that-never-finished"></a>

### การติดตั้งครั้งก่อนที่ไม่เสร็จสมบูรณ์

หากการติดตั้งครั้งก่อนจากตัวติดตั้งเหล่านี้ตัวใดก็ตามถูกขัดจังหวะ เนื่องจากระบบขัดข้องหรือไฟดับ หมายเหตุสีเหลืองอำพันจะแสดง “การติดตั้ง” แอปนั้น “ครั้งก่อนไม่เสร็จสมบูรณ์ เมื่อติดตั้ง ระบบจะเลิกทำการติดตั้งครั้งนั้นก่อน” ซึ่งจะเกิดขึ้นโดยอัตโนมัติเมื่อคุณคลิก **ติดตั้ง**

<a id="what-this-sets-up-beyond-files"></a>

## สิ่งที่ตัวติดตั้งนี้ตั้งค่านอกเหนือจากไฟล์

การ์ดนี้คือรายการที่คุณยอมรับเมื่อคลิก **ติดตั้ง** ใต้ชื่อการ์ดจะแสดง:

> ทั้งหมดนี้ทำด้วยสิทธิ์ของผู้ดูแลระบบ หากการติดตั้งล้มเหลว สิ่งที่เปลี่ยนแปลงไปจะถูกย้อนกลับ และคุณจะได้รับแจ้งหากมีสิ่งใดที่ย้อนกลับไม่ได้ คุณยังสามารถเลิกทำการติดตั้งในภายหลังได้ จากการตั้งค่า ภายใต้ “แอปที่ติดตั้ง” ไฟล์ที่ถูกแทนที่ไว้จะกลับคืนมา ส่วนรันไทม์ที่ติดตั้งไว้จะยังคงอยู่

แต่ละแถวมีชื่อ ป้ายกำกับทางขวาที่บอกว่าเป็นสิ่งชนิดใด และบรรทัดที่บอกว่าสิ่งนั้นทำอะไร ป้ายกำกับสีน้ำเงินตามปกติเป็นรายการทั่วไป ป้ายกำกับสี **เหลืองอำพัน** ระบุสิ่งที่ทำงานด้วยสิทธิ์เต็มรูปแบบ เช่น บริการที่ทำงานในฐานะ LocalSystem ไดรเวอร์ หรือกฎไฟร์วอลล์ที่อนุญาตการเชื่อมต่อขาเข้า โปรดตรวจดูรายการเหล่านั้นให้ถี่ถ้วน

หากรายการว่างเปล่า จะแสดง “ไม่มี: ตัวติดตั้งนี้คัดลอกเฉพาะไฟล์ และการตั้งค่าในคีย์รีจิสทรีของแอปเอง”

รายการนี้คำนวณสำหรับตำแหน่งในช่อง หากคุณเปลี่ยนตำแหน่ง จะแสดง “กำลังตรวจสอบว่าจะตั้งค่าอะไรบ้างที่ตำแหน่งนี้…” สักครู่ และ **ติดตั้ง** จะรอ

<a id="notes-and-what-is-left-out"></a>

### หมายเหตุและสิ่งที่ไม่รวมไว้

ใต้แถวต่างๆ หมายเหตุสีเหลืองอำพันจะบอกสิ่งที่คุณควรทราบ ตัวอย่างเช่น:

- ไม่ได้ใส่ข้อมูลประจำตัวไว้ในตัวติดตั้ง คุณจึงอาจต้องป้อนข้อมูลเหล่านั้นอีกครั้ง
- ตัวเลือก **สิทธิ์การใช้งาน** หรือ **ข้อมูลผู้ใช้** ปิดอยู่ตอนที่สร้าง ข้อมูลนั้นจึงไม่อยู่ในตัวติดตั้ง
- [ใบรับรอง](Glossary#certificate)ที่แอปดูเหมือนจะพึ่งพา ซึ่งจะไม่ถูกติดตั้งเลย
- สิ่งที่ผู้สร้างตัวติดตั้งไม่รวมไว้ และสิ่งที่เพิ่มเข้ามา
- แอปอาจทำงานที่นี่ไม่ได้: “แอปนี้เคยอยู่บน Windows บิลด์” ที่ใหม่กว่า หรือ Windows จะเรียกใช้โปรแกรมบางโปรแกรมของแอป “ผ่านตัวจำลอง”
- ไฟล์จากโฟลเดอร์เอกสารหรือเกมที่บันทึกไว้ จะ “ไปอยู่ภายใต้” โฟลเดอร์ที่ติดตั้ง “ในโฟลเดอร์ชื่อ _external” เนื่องจากโฟลเดอร์ของพีซีเครื่องนี้อยู่นอกโปรไฟล์ของคุณ

จากนั้น สิ่งที่กฎความปลอดภัยไม่รวมไว้แต่ละรายการจะแสดงเป็นสีเหลืองอำพัน พร้อมเหตุผล 20 รายการแรกจะแสดงแบบเต็ม ส่วนที่เหลืออยู่ภายใต้ “ไม่รวมไว้อีก” ตามด้วยจำนวน “รายการ” ซึ่งคุณสามารถเปิดดูได้ การติดตั้งส่วนที่เหลือยังคงดำเนินต่อไปโดยไม่มีสิ่งเหล่านั้น สิ่งที่ถูกปฏิเสธและเหตุผล อธิบายไว้ใน[สิ่งที่อยู่ในตัวติดตั้ง](What-Goes-in-an-Installer#what-the-installer-refuses)

หากไม่สามารถติดตั้งแพคเกจไปยังตำแหน่งที่เลือกได้เลย ข้อความสีแดงจะแสดง “ไม่สามารถติดตั้งแพคเกจนี้ไปยังตำแหน่งนี้ได้” พร้อมเหตุผล

## ตัวเลือก

การ์ดนี้จะแสดงเฉพาะเมื่อตัวติดตั้งมีข้อมูลผู้ใช้หรือข้อมูลสิทธิ์การใช้งาน แต่ละช่องจะทำเครื่องหมายไว้ตั้งแต่ต้น

| ตัวเลือก | สิ่งที่แสดง |
| --- | --- |
| **ข้อมูลผู้ใช้** | “เปิด: การตั้งค่า เอกสาร และเกมที่บันทึกไว้ จะไปยังโฟลเดอร์ปกติของผู้ที่ลงชื่อเข้าใช้อยู่ ปิด: ทั้งหมดจะอยู่ภายใต้โฟลเดอร์ที่ติดตั้ง และจะไม่มีการตั้งค่าให้สิ่งใดทำงาน จากโฟลเดอร์นั้น” หากตัวติดตั้งระบุว่ามีข้อมูลของใคร บรรทัดด้านล่างจะแสดง “ข้อมูลนี้เป็นของ” ตามด้วยบัญชีนั้น |
| **สิทธิ์การใช้งาน** | “ไฟล์การเปิดใช้งานและสิทธิ์การใช้งาน รวมถึงค่ารีจิสทรีที่เก็บสิทธิ์การใช้งาน บางรายการอาจต้องเปิดใช้งานใหม่ที่นี่” |

การเปลี่ยนช่องใดจะเปลี่ยนรายการด้านบนให้ตรงกันทันที

ข้อมูลผู้ใช้จะไปยัง **ผู้ที่ลงชื่อเข้าใช้** Windows อยู่เสมอ แม้จะมีการพิมพ์ชื่อผู้ดูแลระบบคนอื่นที่ข้อความแจ้ง UAC ก็ตาม หากตัวติดตั้งไม่สามารถทราบได้ว่าเป็นใคร จะแจ้งให้ทราบ ไม่รวมการตั้งค่าต่อผู้ใช้ไว้ และวางข้อมูลผู้ใช้ไว้ภายใต้โฟลเดอร์ที่ติดตั้งแทนการคาดเดา หากไม่มีผู้ใดลงชื่อเข้าใช้เซสชันนั้น ข้อมูลผู้ใช้และการตั้งค่าต่อผู้ใช้จะไปยังบัญชีที่ใช้เรียกใช้ตัวติดตั้ง และจะแจ้งให้ทราบเช่นกัน

<a id="preview-changes"></a>

## แสดงตัวอย่างการเปลี่ยนแปลง

**แสดงตัวอย่างการเปลี่ยนแปลง** จะคำนวณสิ่งที่การติดตั้งจะทำอย่างแม่นยำ โดยไม่เปลี่ยนแปลงสิ่งใด ระบบจะตรวจสอบว่ามีพื้นที่เพียงพอ แตกไฟล์แพคเกจไปยังโฟลเดอร์ส่วนตัว คำนวณการเปลี่ยนแปลง แล้วลบโฟลเดอร์นั้นอีกครั้ง การ์ดผลลัพธ์มีหัวเรื่อง “ตัวอย่าง: ยังไม่มีการเปลี่ยนแปลงสิ่งใด” พร้อม **การเปลี่ยนแปลงที่วางแผนไว้** และรายการการเปลี่ยนแปลง โดยแสดงบริการ งาน และทางลัดก่อน หน้าต่างจะแสดง 300 รายการแรก แล้วบอกว่ายังมีอีกกี่รายการ

การแสดงตัวอย่างไม่ตรวจสอบแฮชของแต่ละไฟล์ แฮชของแพคเกจทั้งหมดได้รับการตรวจสอบแล้วตอนที่เปิดหน้าต่าง

<a id="install"></a>

## ติดตั้ง

**ติดตั้ง** จะเป็นสีเทาจนกว่าจะใช้ตำแหน่งนั้นได้ และรายการเป็นของตำแหน่งนั้น หากไม่สามารถติดตั้งแพคเกจไปยังตำแหน่งนั้นได้เลย บรรทัดข้างปุ่มจะแสดงว่า “ติดตั้ง” ใช้ไม่ได้ เนื่องจากไม่สามารถติดตั้งแพคเกจนี้ ไปยังตำแหน่งนี้ได้ และเหตุผลจะแสดงเป็นสีแดงใน **สิ่งที่ตัวติดตั้งนี้ตั้งค่านอกเหนือจากไฟล์** เมื่อคุณคลิก:

1. ตัวติดตั้งจะคำนวณรายการอีกครั้ง หากสิ่งที่จะทำเปลี่ยนไปตั้งแต่ที่คุณดู ระบบจะไม่ติดตั้งสิ่งใด แสดงรายการใหม่ และแจ้งว่า “สิ่งที่ตัวติดตั้งจะทำที่นี่เปลี่ยนไปแล้ว จึงไม่มีการติดตั้งสิ่งใด โปรดตรวจดูรายการด้านล่าง แล้วคลิก ‘ติดตั้ง’ อีกครั้งหากเป็นสิ่งที่คุณต้องการ”
2. ตรวจสอบว่ามีพื้นที่บนทุกไดรฟ์ที่จะเขียนข้อมูล
3. แตกไฟล์แพคเกจไปยังโฟลเดอร์ที่เฉพาะผู้ดูแลระบบเท่านั้นใช้ได้ โดยตรวจสอบแฮชของแต่ละไฟล์ขณะแตกออกมา
4. ติดตั้ง โดยจดการเปลี่ยนแปลงแต่ละรายการลงใน[บันทึกการติดตั้ง](Glossary#journal)ก่อน เพื่อให้เลิกทำได้
5. อ่านไฟล์ทุกไฟล์ที่ติดตั้งกลับมา และตรวจสอบแฮช
6. เริ่มบริการที่ตั้งค่าให้เริ่มทำงานเอง

ที่ด้านล่าง คุณจะเห็นสิ่งที่ตัวติดตั้งกำลังทำ จำนวนนับหากมี เวลาที่ใช้ไป แถบความคืบหน้า และปุ่ม **ยกเลิก** ขั้นตอนที่คุณอาจเห็นได้แก่ “กำลังเตรียมพร้อม…” “กำลังแตกไฟล์” “กำลังตรวจสอบแพคเกจ” “กำลังเลิกทำการติดตั้งครั้งก่อนที่ไม่เสร็จสมบูรณ์” “กำลังติดตั้งรันไทม์” “กำลังคัดลอกไฟล์” “กำลังตั้งค่าบริการ” “กำลังตั้งค่าไดรเวอร์” “กำลังเขียนการตั้งค่ารีจิสทรี” “กำลังคืนค่าข้อมูลสิทธิ์การใช้งาน” “กำลังตั้งค่างานที่จัดกำหนดการไว้” “กำลังสร้างทางลัด” “กำลังตั้งค่าตัวแปรสภาพแวดล้อม” “กำลังเพิ่มแอปลงในการตั้งค่า” และ “กำลังตรวจสอบสิ่งที่ติดตั้ง”

**ยกเลิก** จะแสดง “กำลังยกเลิกหลังจากขั้นตอนปัจจุบัน…” แล้วจึงแสดง “กำลังย้อนกลับสิ่งที่เปลี่ยนแปลง” การปิดหน้าต่างระหว่างติดตั้งจะให้ผลเหมือนกับ **ยกเลิก**: หน้าต่างจะยังคงอยู่จนกว่าจะย้อนกลับทุกอย่างเรียบร้อย หากยังไม่มีการเปลี่ยนแปลงสิ่งใด จะแสดง “ยกเลิกแล้ว ไม่มีการเปลี่ยนแปลงสิ่งใด”

<a id="the-hash-check"></a>

## การตรวจสอบแฮช

ตัวติดตั้งตรวจสอบ[แฮช](Glossary#hash)สามครั้ง:

1. **เมื่อหน้าต่างเปิดขึ้น**: แฮชของแพคเกจทั้งหมด สำเนาที่ไม่ครบ หรือสำเนาที่ถูกแก้ไขหลังจากสร้าง จะถูกปฏิเสธก่อนที่จะอ่านสิ่งใดภายใน
2. **ขณะแตกไฟล์**: แฮชของแต่ละไฟล์ ก่อนที่จะเขียนสิ่งใดลงในตำแหน่งของไฟล์นั้น
3. **หลังจากติดตั้ง**: อ่านแต่ละไฟล์ที่ติดตั้งกลับมา และตรวจสอบอีกครั้ง

แฮชตรวจจับความเสียหาย และการเปลี่ยนแปลงโดยผู้ที่ไม่ได้อัปเดตแฮชไปด้วย แต่แฮชไม่ได้พิสูจน์ว่าใครเป็นผู้สร้างตัวติดตั้ง มีเพียง[ลายเซ็น](Glossary#signature)เท่านั้นที่ทำได้

<a id="the-result"></a>

## ผลลัพธ์

การ์ดผลลัพธ์จะปรากฏที่ด้านบน โดยมีหัวเรื่อง “ผลการติดตั้ง”

| ข้อความ | ความหมาย |
| --- | --- |
| “ติดตั้งแอปพลิเคชันแล้ว และผ่านการตรวจสอบแฮช” | ทุกอย่างเรียบร้อย หากกฎไม่รวมสิ่งใดไว้ จะเพิ่ม “โดยไม่มีรายการที่แสดงว่าไม่รวมไว้ด้านล่าง” |
| “การติดตั้งถูกยกเลิก และสิ่งที่เปลี่ยนแปลงไปได้รับการย้อนกลับแล้ว” | คุณยกเลิก |
| “การติดตั้งล้มเหลว และสิ่งที่เปลี่ยนแปลงไปได้รับการย้อนกลับแล้ว” | มีบางอย่างล้มเหลว สิ่งที่เปลี่ยนแปลงไปได้รับการย้อนกลับแล้ว ยกเว้นรันไทม์ที่ติดตั้งไว้ สิ่งที่แสดงเป็นสีเหลืองอำพันด้านล่างจะยังคงอยู่ พร้อมบอกเหตุผล เช่น บริการที่จะหายไปเมื่อเริ่มพีซีใหม่เท่านั้น |
| “การติดตั้งล้มเหลว และไม่สามารถย้อนกลับสิ่งที่เปลี่ยนแปลงได้ทั้งหมด สิ่งที่เหลืออยู่แสดงอยู่ด้านล่าง และการติดตั้งครั้งถัดไปจะลองอีกครั้ง” | โปรดอ่านรายการ การเรียกใช้ตัวติดตั้งอีกครั้งจะพยายามย้อนกลับอีกครั้ง |
| “การติดตั้งเสร็จสิ้นอย่างไม่สมบูรณ์ โปรดตรวจดูปัญหาด้านล่าง” | โปรดอ่านข้อความด้านล่าง |

จากนั้นจะมีไทล์สามไทล์: **การเปลี่ยนแปลงที่ทำแล้ว** (หรือ **การเปลี่ยนแปลงที่ย้อนกลับแล้ว** หลังจากล้มเหลว) **คำเตือน** และ **ข้อผิดพลาด** ป้ายกำกับจะแสดง **แฮชของแพคเกจถูกต้อง** และ **ไฟล์ที่ติดตั้งถูกต้อง** หรือ **แฮชของแพคเกจไม่ถูกต้อง** และ **ไฟล์ที่ติดตั้งไม่ถูกต้อง** เป็นสีแดง คำเตือนสูงสุดห้ารายการและข้อผิดพลาดทุกรายการจะแสดงเป็นข้อความ “ส่วนประกอบที่ต้องใช้รายการหนึ่ง ต้องเริ่มระบบใหม่ จึงจะเสร็จสมบูรณ์ โปรดเริ่ม Windows ใหม่ แล้วเปิดแอป” หมายความว่ารันไทม์ขอให้เริ่มระบบใหม่

**การเปลี่ยนแปลง** พร้อมจำนวน จะเปิดรายการสิ่งที่ทำไป สูงสุด 300 รายการ หากการติดตั้งไม่เสร็จสิ้นอย่างสมบูรณ์ เส้นทางของ[ไฟล์บันทึก](Glossary#log)จะแสดงเป็น **ไฟล์บันทึก**

หลังจากติดตั้งเรียบร้อย ปุ่มที่ด้านล่างจะเปลี่ยนเป็น **ปิด** และ **เปิดโฟลเดอร์ที่ติดตั้ง**

<a id="where-things-end-up"></a>

## สิ่งต่างๆ จะไปอยู่ที่ใด

- **ไฟล์ของโปรแกรม** จะไปอยู่ในตำแหน่งที่ติดตั้ง
- **ข้อมูลผู้ใช้** เมื่อทำเครื่องหมายช่องนั้นไว้ จะไปยัง AppData เอกสาร และเกมที่บันทึกไว้ของบัญชีที่ลงชื่อเข้าใช้ และไปยัง ProgramData โฟลเดอร์เอกสารหรือเกมที่บันทึกไว้ที่พีซีเครื่องนี้เก็บไว้นอกโปรไฟล์ของคุณ จะไม่มีการเขียนลงไป ไฟล์เหล่านั้นจะไปอยู่ภายใต้ตำแหน่งที่ติดตั้ง ใน `_external` และรายการจะแจ้งเรื่องนี้ก่อน เมื่อไม่ได้ทำเครื่องหมายช่องนั้น ข้อมูลผู้ใช้ทั้งหมดจะไปอยู่ภายใต้ตำแหน่งที่ติดตั้ง
- **ทางลัด** จะไปยังเดสก์ท็อปและเมนูเริ่มของพีซีเครื่องนี้: ของคุณ หรือของทุกคนหากเดิมอยู่ที่นั่น
- **Path** จะได้รับการเพิ่มเฉพาะรายการของแอป สิ่งอื่นใน Path จะไม่เปลี่ยนแปลง
- **สิ่งที่แอปอื่นมีอยู่แล้วที่นี่ จะยังคงเป็นของแอปนั้น** ชนิดไฟล์ ชนิดลิงก์ คลาส COM บริการ แหล่งที่มาของบันทึกเหตุการณ์ ฟอนต์ หรือสิ่งใดในลักษณะนี้ที่เป็นของสิ่งอื่นอยู่แล้ว จะถูกปล่อยไว้ตามเดิม และตัวติดตั้งจะแจ้งให้ทราบ ตัวอย่างเช่น แอปที่คาดว่าจะเปิดลิงก์ `http` ต้องตั้งเป็นค่าเริ่มต้นอีกครั้งในการตั้งค่า
- **การตั้งค่า** จะมีรายการของแอป คุณจึงถอนการติดตั้งแอปได้เหมือนแอปอื่นๆ โปรดดู[การเลิกทำการติดตั้ง](Undoing-an-Install)

<a id="common-reasons-it-refuses"></a>

## สาเหตุทั่วไปที่ตัวติดตั้งปฏิเสธ

| สิ่งที่คุณเห็น | สาเหตุ | สิ่งที่ควรทำ |
| --- | --- | --- |
| “แอปนี้ไม่สามารถทำงานบนพีซีเครื่องนี้ได้ จึงไม่มีการเปลี่ยนแปลงสิ่งใด” | โปรแกรมของแอปสร้างขึ้นสำหรับโปรเซสเซอร์ชนิดอื่น หรือต้องใช้ Windows รุ่นที่ใหม่กว่า | ติดตั้งบนพีซีที่ตรงกับเครื่องเก่า |
| “พื้นที่ไม่เพียงพอ จึงไม่มีการเปลี่ยนแปลงสิ่งใด” | พื้นที่ว่างไม่เพียงพอบนไดรฟ์ที่ต้องเขียนข้อมูล | เพิ่มพื้นที่ว่าง หรือเลือกตำแหน่งบนไดรฟ์อื่น |
| “มีการติดตั้งหรือถอนการติดตั้งอื่นกำลังทำงานอยู่” | ทำงานได้ทีละรายการเท่านั้น | รอให้เสร็จ แล้วลองอีกครั้ง |
| ไฟล์หนึ่ง “มีชื่อที่ Windows เวอร์ชันนี้เปิดเป็นอุปกรณ์แทนที่จะเปิดเป็นไฟล์” | แอปมีไฟล์ที่มีชื่อลักษณะเช่น `aux.h` ซึ่ง Windows ก่อน Windows 11 ไม่สามารถเก็บได้ | ติดตั้งบน Windows 11 |
| โฟลเดอร์ข้อมูล เช่น `%AppData%` อยู่ภายใต้ลิงก์ | ตัวติดตั้งจะไม่เขียนผ่านลิงก์ | ยกเลิกการทำเครื่องหมาย **ข้อมูลผู้ใช้** และ **สิทธิ์การใช้งาน** แล้วติดตั้งโดยไม่มีข้อมูลเหล่านั้น |
