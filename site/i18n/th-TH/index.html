ย้ายโปรแกรม Windows ที่ติดตั้งไว้ไปยังพีซีเครื่องใหม่

WinAppMigrator เปลี่ยนแอปที่ติดตั้งไว้บนพีซี Windows เครื่องหนึ่ง ให้เป็นตัวติดตั้งเดียวที่คุณเรียกใช้บนอีกเครื่องหนึ่งได้ แม้แอปจะอยู่บนพีซี Windows 7 เครื่องเก่าในเครือข่ายของคุณ บนไดรฟ์ที่ถอดออกมาจากเครื่องที่กำลังจะเสีย หรือบนอิมเมจของไดรฟ์นั้น และตัวติดตั้งดั้งเดิมหายไปนานแล้วก็ตาม

สถานการณ์ที่ช่วยได้

ย้ายไปยังพีซีเครื่องใหม่

แอปจะย้ายมาได้โดยไม่ต้องตามหาไฟล์ติดตั้ง ไฟล์สิทธิ์การใช้งาน หรือการตั้งค่าของแอป

เริ่มต้นใช้งาน

พีซีเครื่องเก่าเปิดไม่ติด

ถอดไดรฟ์ออกมา เชื่อมต่อกับพีซีที่ใช้งานได้ แล้วสร้างตัวติดตั้งจากแอปบนไดรฟ์นั้น หากไดรฟ์อาจกำลังจะเสีย ให้สร้างอิมเมจของไดรฟ์ก่อน แล้วสร้างตัวติดตั้งจากอิมเมจ เนื่องจากการอ่านไดรฟ์ที่กำลังจะเสียอาจทำให้ไดรฟ์เสียสนิท

จากไดรฟ์หรืออิมเมจดิสก์

ย้ายออกจาก Windows 7, Vista, 8 หรือ 8.1

แอปจาก Windows เหล่านี้ย้ายไปอยู่บน Windows 10 หรือ 11 ได้ โดยจัดการสิ่งที่แตกต่างไว้ให้: Windows แบบ 32 บิต VirtualStore และรันไทม์ DirectX 9

แอปจาก Windows รุ่นเก่า

พีซีเครื่องเก่ายังทำงานอยู่ในเครือข่ายของคุณ

เรียกใช้ WinAppMigrator Client ซึ่งเป็นโปรแกรมขนาดเล็กที่ลงนามแล้วบนเครื่องนั้น พิมพ์รหัสที่โปรแกรมแสดง แล้วเลือกแอป เฉพาะสิ่งที่การสร้างต้องใช้เท่านั้นที่ส่งผ่านเครือข่าย โดยเข้ารหัสไว้ ไม่ต้องถอดสิ่งใดออกจากพีซี

จากพีซีผ่านเครือข่าย

ไฟล์ติดตั้งหายไป หรือบริษัทผู้ผลิตไม่อยู่แล้ว

WinAppMigrator ทำงานย้อนกลับจากสิ่งที่ติดตั้งไว้: ไฟล์ของแอป รายการรีจิสทรี บริการ และรันไทม์ของ Microsoft ที่แอปต้องใช้

วิธีการทำงาน

แอปเดียวกันบนพีซีหลายเครื่อง

ตัวติดตั้งที่สร้างขึ้นสามารถแสดงตัวอย่าง ติดตั้ง และถอนการติดตั้งจากพร้อมท์คำสั่งได้ สคริปต์จึงติดตั้งแอปเดียวกันบนพีซีแต่ละเครื่องได้

บรรทัดคำสั่ง

วิธีการทำงาน

  1. เลือกแอป

    จากพีซีเครื่องนี้ ไดรฟ์จากพีซีเครื่องอื่นที่เสียบเข้ากับเครื่องนี้ อิมเมจ .vhd หรือ .vhdx ที่แอปแนบแบบอ่านอย่างเดียว หรือพีซีเครื่องอื่นในเครือข่ายของคุณ

  2. ดูสิ่งที่จะรวมไว้

    หน้าจอจะบอกว่าตัวติดตั้งอาจมีขนาดเท่าใด พื้นที่เพียงพอหรือไม่ และมีอะไรอยู่ภายใน ยกเลิกการทำเครื่องหมายสิ่งที่คุณไม่ต้องการ และทำเครื่องหมายสิ่งที่ดูเกี่ยวข้อง ซึ่งการจับคู่ชื่อแบบตรงตัวมองข้ามไป

  3. สร้างตัวติดตั้ง

    คุณจะได้ไฟล์ .exe เพียงไฟล์เดียว ซึ่งตั้งชื่อตามสิ่งที่อยู่ภายใน แอปที่ใหญ่เกินกว่าจะอยู่ในไฟล์เดียว จะมาเป็นไฟล์ .exe และไฟล์ข้อมูลที่ต้องอยู่ด้วยกัน

  4. เรียกใช้บนพีซีเครื่องอื่น

    ตัวติดตั้งจะตรวจสอบแฮชของแพคเกจก่อนเขียนสิ่งใด จากนั้นติดตั้ง แล้วอ่านสิ่งที่ติดตั้งกลับมาตรวจสอบอีกครั้ง หากเกิดข้อผิดพลาด หรือคุณยกเลิก ตัวติดตั้งจะย้อนกลับสิ่งที่ทำไป ยกเว้นรันไทม์ที่ติดตั้งไว้ และจะทิ้งตัวถอนการติดตั้งไว้ในการตั้งค่า

ขั้นตอนทั้งหมดตั้งแต่ต้นจนจบ

สิ่งที่อยู่ในตัวติดตั้ง

  • ไฟล์ของโปรแกรม ซึ่งค้นพบผ่านบันทึกของ MSI และ Inno Setup ไฟล์บันทึกของ NSIS, App Paths และโฟลเดอร์ที่ตั้งชื่อตรงกับผลิตภัณฑ์
  • รายการรีจิสทรี: คีย์ระดับเครื่องของแอป คลาส COM ชนิดไฟล์ โพรโทคอลลิงก์ คำสั่งเมนู และส่วนขยายเชลล์
  • บริการและไดรเวอร์ งานที่จัดกำหนดการไว้ ทางลัด กฎไฟร์วอลล์ ฟอนต์ และตัวแปรสภาพแวดล้อมที่เก็บเส้นทางของแอป
  • รันไทม์: รันไทม์ Visual C++ และ .NET รุ่นใหม่ที่แอปต้องใช้ ซึ่งจะดาวน์โหลดเมื่อคุณสร้างตัวติดตั้ง แล้วใส่ไว้ภายใน จึงติดตั้งได้โดยไม่ต้องใช้อินเทอร์เน็ต เว้นแต่ในตอนนั้นจะดาวน์โหลดรันไทม์บางรายการไม่ได้
  • ข้อมูลผู้ใช้และข้อมูลสิทธิ์การใช้งาน หากคุณเลือก WinAppMigrator ไม่เคยหลบเลี่ยงการเปิดใช้งาน และสิทธิ์การใช้งานที่ผูกกับเครื่องเก่าอาจต้องเปิดใช้งานใหม่
  • ไม่รวมข้อมูลประจำตัวเด็ดขาด ค่าและไฟล์ที่ดูเหมือนรหัสผ่าน โทเค็น หรือคีย์ส่วนตัว จะไม่รวมไว้ และจะแจ้งชื่อให้ทราบก่อนที่คุณจะสร้าง

ทุกสิ่งที่รวมไว้ และสิ่งที่ไม่รวมไว้

ในภาษาของคุณ สำหรับทุกคน

แอป ตัวติดตั้งทุกตัวที่แอปสร้าง และไคลเอ็นต์สำหรับพีซีเครื่องเก่า รองรับ 24 ภาษา โดยเริ่มต้นด้วยภาษาที่ Windows ใช้อยู่ ตัวติดตั้งจะใช้ภาษาของพีซีที่เรียกใช้ ไม่ใช่ภาษาของพีซีที่สร้างตัวติดตั้ง และภาษาอาหรับ เปอร์เซีย อูรดู และฮีบรู จะจัดวางจากขวาไปซ้าย ทุกภาษายกเว้นภาษาอังกฤษแปลด้วยเครื่อง หากภาษาใดอ่านแล้วไม่ถูกต้อง โปรดแจ้งให้ทราบ

ตัวควบคุมทุกตัวเข้าถึงได้ด้วยแป้นพิมพ์ และมีชื่อสำหรับโปรแกรมอ่านหน้าจอ และหน้าต่างจะเป็นไปตามธีมความคมชัด ขนาดข้อความ และเอฟเฟกต์ภาพเคลื่อนไหวของ Windows หน้าต่างเหล่านี้ได้รับการตรวจสอบตาม WCAG 2.2 AA และรายงานความสอดคล้องจะอธิบายวิธีการตรวจสอบ

ภาษาและการช่วยสำหรับการเข้าถึง

ก่อนที่คุณจะพึ่งพา

ทุกครั้งที่มีการพุชไปยังโปรเจกต์ จะมีการย้ายแอปโอเพนซอร์สจริงห้าแอป ได้แก่ 7-Zip, PuTTY, Eclipse Mosquitto, windows_exporter และ Git LFS จากเครื่องทดสอบเครื่องหนึ่งไปยังเครื่องใหม่ และให้ Windows เองใช้งานสิ่งที่คืนค่าแล้ว แอปเหล่านั้นเป็นแอปขนาดเล็ก ที่ทำงานเรียบร้อยบนเครื่องที่สะอาด การทดสอบเหล่านั้นยังไม่เคยเรียกใช้บน Windows 10 และ 11 รุ่นเดสก์ท็อปบน x64 และยังไม่เคยลองแอปที่ต้องเปิดใช้งานแบบออนไลน์ การโหลดไดรเวอร์ และการเริ่มระบบใหม่หลังติดตั้งเลย

ดังนั้น โปรดลองใช้ตัวติดตั้งก่อนที่จะพึ่งพา และสร้างอิมเมจของไดรฟ์ที่กำลังจะเสียก่อนที่จะอ่าน WinAppMigrator มีไว้สำหรับซอฟต์แวร์ที่คุณได้รับอนุญาตให้ย้ายเท่านั้น

รับ WinAppMigrator

  1. ดาวน์โหลด WinAppMigrator-v${version}.exe จาก รุ่นล่าสุดที่เผยแพร่ ไม่ต้องติดตั้งสิ่งใด
  2. เรียกใช้ไฟล์ Windows จะขออนุมัติจากผู้ดูแลระบบ เนื่องจากทั้งการอ่านไดรฟ์อื่นและการติดตั้งบริการต้องใช้สิทธิ์นี้ ลายเซ็นของไฟล์ระบุชื่อ Randy Northrup
  3. เลือกแอป แล้วหน้าจอจะแสดงสิ่งที่จะรวมไว้ในตัวติดตั้งของแอปนั้น ก่อนที่คุณจะคลิกสิ่งใด
