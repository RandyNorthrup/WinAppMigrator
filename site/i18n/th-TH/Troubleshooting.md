# การแก้ไขปัญหา

ค้นหาสิ่งที่คุณเห็นด้านล่าง ตามสิ่งที่เกิดขึ้น หรือตามคำบนหน้าจอ คำที่อยู่ในเครื่องหมายคำพูดคือสิ่งที่โปรแกรมแสดง ซึ่งบางครั้งมีชื่อหรือตัวเลขอยู่ตรงกลาง

หากไม่มีสิ่งใดในหน้านี้ช่วยได้ โปรดดู[การขอความช่วยเหลือ](#getting-help)ที่ท้ายหน้า

<a id="the-window-could-not-open"></a>

## ไม่สามารถเปิดหน้าต่างได้

**สิ่งที่คุณเห็น** กล่องข้อความแทนหน้าต่าง:

- จากแอป: “ไม่สามารถเปิดหน้าต่างได้” และ “โปรแกรมนี้ต้องใช้ Direct3D 12 ในการแสดงหน้าต่าง ซึ่งไดรเวอร์กราฟิกรุ่นเก่า หรือเครื่องเสมือนอาจไม่มี”
- จากตัวติดตั้ง: ข้อความเดียวกัน และ “แต่ยังคงติดตั้งได้โดยไม่ต้องใช้หน้าต่าง: ให้เรียกใช้ไฟล์นี้ จากพร้อมท์คำสั่งที่เรียกใช้ในฐานะผู้ดูแลระบบ พร้อมกับ --apply และใช้ --target-root ตามด้วยโฟลเดอร์เพื่อเลือกตำแหน่ง”
- จากตัวถอนการติดตั้ง: ข้อความเดียวกัน และ “แต่ยังคงถอนการติดตั้งได้โดยไม่ต้องใช้หน้าต่าง จากพร้อมท์คำสั่งที่เรียกใช้ในฐานะผู้ดูแลระบบ:” พร้อมคำสั่งที่ต้องใช้

**สาเหตุ** หน้าต่างแสดงผลด้วย [Direct3D 12](Glossary#direct3d-12) และไม่มีสิ่งอื่นที่ใช้แสดงผลแทนได้

**สิ่งที่ควรทำ**

- อัปเดตไดรเวอร์กราฟิกของพีซี
- สำหรับตัวติดตั้งหรือตัวถอนการติดตั้ง ให้ใช้บรรทัดคำสั่ง โปรดดู[บรรทัดคำสั่ง](Command-Line)
- แอปไม่มีบรรทัดคำสั่ง โปรดสร้างตัวติดตั้งบนพีซีเครื่องอื่น: คุณสามารถเชื่อมต่อไดรฟ์ของพีซีเครื่องเก่าเข้ากับเครื่องนั้นได้ โปรดดู[การย้ายจากไดรฟ์ที่เชื่อมต่อ](Moving-from-a-Connected-Drive) พีซีเครื่องนั้นยังสามารถอ่านเครื่องเก่าผ่านเครือข่ายได้ด้วย โปรดดู[การย้ายจากพีซีผ่านเครือข่าย](Moving-over-the-Network)

## การสร้าง

<a id="picking-a-drive-or-a-disk-image"></a>

### การเลือกไดรฟ์หรืออิมเมจดิสก์

| สิ่งที่คุณเห็น | สิ่งที่ควรทำ |
| --- | --- |
| ไดรฟ์ “ดูไม่เหมือนไดรฟ์ระบบของ Windows (ไม่มี \Windows และ \Users) โปรดเลือกรากของไดรฟ์จากพีซีเครื่องอื่น” | เลือกระดับบนสุดของไดรฟ์ เช่น `E:\` ไม่ใช่โฟลเดอร์บนไดรฟ์ ตรวจสอบว่าเป็นไดรฟ์ที่ติดตั้ง Windows ไว้ |
| อิมเมจ “ไม่ใช่อิมเมจดิสก์ที่ Windows แนบได้ (.vhd หรือ .vhdx)” | เลือกไฟล์ `.vhd` หรือ `.vhdx` โปรดบันทึกดิสก์ VMware หรือ VirtualBox เป็นชนิดใดชนิดหนึ่งนี้ก่อน สำหรับจุดตรวจสอบของ Hyper-V ซึ่งเป็นไฟล์ `.avhdx` ให้ส่งออกดิสก์ของเครื่องเสมือน |
| “ไม่สามารถแนบ” อิมเมจ “ได้: Windows แนบอิมเมจนี้อยู่แล้ว และสิ่งที่แนบไว้อาจกำลังเขียนข้อมูลลงไป” | อิมเมจเปิดอยู่ที่อื่น เช่น ถูกเมานต์ในตัวสำรวจไฟล์ โปรดเลือกไดรฟ์ของอิมเมจภายใต้ **ไดรฟ์ที่เชื่อมต่อ…** แทน หรือถอดอิมเมจออก แล้วเลือกอีกครั้ง |
| อิมเมจ “ไม่มีโวลุ่มที่มี Windows ซึ่งอ่านได้ โวลุ่มที่เข้ารหัสด้วย BitLocker ต้องปลดล็อกก่อน” | ตรวจสอบว่าเป็นอิมเมจของไดรฟ์ที่ติดตั้ง Windows ไว้ หากถูกล็อกด้วย [BitLocker](Glossary#bitlocker) ให้เมานต์อิมเมจใน Windows ด้วยตนเอง ปลดล็อก แล้วเลือกไดรฟ์ของอิมเมจภายใต้ **ไดรฟ์ที่เชื่อมต่อ…** |
| อิมเมจ “เป็นดิสก์ส่วนต่าง ซึ่งเก็บเฉพาะสิ่งที่เปลี่ยนไปจากดิสก์ต้นแบบ” | ผสานอิมเมจเข้ากับดิสก์ต้นแบบด้วย “แก้ไขดิสก์” ของ Hyper-V แล้วเลือกดิสก์ต้นแบบนั้น |
| “ไม่สามารถแนบ” อิมเมจ “ได้:” ตามด้วยเหตุผลอื่น | เหตุผลนั้นเป็นของ Windows เอง โปรดอ่านเหตุผล ตรวจสอบว่าไม่มีสิ่งอื่นใช้อิมเมจอยู่ แล้วลองอีกครั้ง |

<a id="reading-a-pc-over-the-network"></a>

### การอ่านพีซีผ่านเครือข่าย

รายการทั้งหมด รวมถึงสิ่งที่ไคลเอ็นต์แสดงบนพีซีเครื่องเก่า อยู่ใน[การย้ายจากพีซีผ่านเครือข่าย](Moving-over-the-Network#if-something-goes-wrong)

| สิ่งที่คุณเห็น | สิ่งที่ควรทำ |
| --- | --- |
| พีซีเครื่องเก่าไม่อยู่ในรายการภายใต้ **2. เลือกพีซีเครื่องเก่า** | ตรวจสอบว่าไคลเอ็นต์ทำงานอยู่บนเครื่องนั้นและแสดงรหัส และพีซีทั้งสองเครื่องอยู่ในเครือข่ายเดียวกัน จากนั้นพิมพ์ชื่อหรือที่อยู่ของเครื่อง หากต้องผ่านเราเตอร์ ให้พิมพ์ที่อยู่ ไฟร์วอลล์อื่นที่ไม่ใช่ไฟร์วอลล์ Windows ต้องอนุญาต TCP 47732 และ UDP 47731 |
| “ไม่พบ” ชื่อนั้น “บนเครือข่าย” | พิมพ์ที่อยู่ของพีซีเครื่องเก่าแทน |
| “ไม่สามารถติดต่อพีซีเครื่องเก่าได้:” ตามด้วยเหตุผล | ตรวจสอบว่าไคลเอ็นต์ยังทำงานอยู่ และชื่อหรือที่อยู่ถูกต้อง |
| “รหัสนี้ไม่ใช่รหัสที่พีซีเครื่องเก่าแสดง โปรดตรวจสอบแล้วลองอีกครั้ง” | พิมพ์รหัสที่ไคลเอ็นต์แสดงอยู่ในขณะนี้ หลังจากใส่รหัสผิดห้าครั้ง ไคลเอ็นต์จะสร้างรหัสใหม่ หลังจาก 20 ครั้ง ไคลเอ็นต์จะไม่ให้จับคู่ใดๆ จนกว่าคุณจะเริ่มไคลเอ็นต์อีกครั้ง |
| บนพีซีเครื่องเก่า Windows แจ้งว่าไม่ทราบผู้เผยแพร่ของไคลเอ็นต์ | กรณีนี้เป็นเรื่องปกติเฉพาะบน Windows 7 ที่ไม่มีใบรับรองรากปี 2020 ของ Microsoft ซึ่งไม่สามารถตรวจสอบลายเซ็นของไคลเอ็นต์ได้ ในกรณีนั้น ให้เลือก **ใช่** เฉพาะสำหรับไคลเอ็นต์ที่คุณบันทึกจากแอปด้วยตนเอง ในกรณีอื่น ข้อความแจ้งควรระบุชื่อ Randy Northrup หากไม่ใช่ อย่าเรียกใช้สำเนานั้น |
| แอปไม่สามารถอ่านพีซีเครื่องเก่าได้อีก หลังจากหยุดไปนาน | ไคลเอ็นต์จะตัดการเชื่อมต่อที่แอปไม่ได้ร้องขอสิ่งใดเป็นเวลา 30 นาที คลิก **ยกเลิกการเชื่อมต่อ** แล้วจับคู่อีกครั้ง |

| แถวแสดง “ไม่รวมไว้ด้วย:” | สิ่งที่คุณยกเลิกการทำเครื่องหมาย ทำให้แถวนี้ไม่รวมไว้ไปด้วย | ทำเครื่องหมายสิ่งนั้นกลับคืน หากคุณต้องการแถวนี้ |
| “สิ่งที่เหลืออยู่ไม่สามารถสร้างเป็นแพคเกจได้” | สิ่งที่คุณยกเลิกการทำเครื่องหมาย ทำให้ไม่เหลือสิ่งใดที่สร้างได้ | ทำเครื่องหมายบางสิ่งกลับคืน |
| “ข้อมูลสิทธิ์การใช้งานในสิ่งที่คุณไม่รวมไว้ จะยังคงรวมอยู่” | สิทธิ์การใช้งานเป็นไปตามตัวเลือก **ข้อมูลสิทธิ์การใช้งานและการเปิดใช้งาน** เท่านั้น | ยกเลิกการทำเครื่องหมายตัวเลือกนั้น หากคุณต้องการนำสิทธิ์การใช้งานออก |

<a id="create-installer-stays-greyed-out"></a>

### ปุ่มสร้างตัวติดตั้งยังคงเป็นสีเทา

ปุ่มจะรอจนกว่าสิ่งต่อไปนี้จะเป็นจริงทั้งหมด:

- การตรวจดูแอปเสร็จสิ้นแล้ว สำหรับตัวเลือกตามที่เป็นอยู่ในตอนนี้ (“กำลังตรวจสอบว่ามีอะไรที่ต้องไปด้วยกัน…” หมายความว่ายังคงคำนวณว่า การยกเลิกการทำเครื่องหมายครั้งล่าสุดของคุณทำให้สิ่งใดไม่รวมไว้ไปด้วย)
- **โฟลเดอร์ผลลัพธ์** เป็นเส้นทางแบบเต็ม เช่น `D:\Installers` (“โปรดใส่เส้นทางโฟลเดอร์แบบเต็ม เช่น D:\Installers”)
- มีพื้นที่เพียงพอบนไดรฟ์นั้น

| “พื้นที่ไม่เพียงพอ” ตามด้วยพื้นที่ที่ไดรฟ์ต้องใช้และที่มีอยู่ | เลือกโฟลเดอร์ผลลัพธ์บนไดรฟ์อื่น หรือนำบางรายการออก ตัวเลขนี้คือขนาดสูงสุดที่การสร้างอาจใช้ก่อนการบีบอัด จึงอาจมากกว่าขนาดของตัวติดตั้งจริง |
| ไดรฟ์ “ไม่ได้แจ้งว่ามีพื้นที่เท่าใด” | การสร้างจะดำเนินต่อโดยไม่ตรวจสอบไดรฟ์นั้น โปรดตรวจสอบให้แน่ใจว่ามีพื้นที่เพียงพอ |
| ไดรฟ์ FAT32 และแอปขนาดใหญ่ | FAT32 ไม่สามารถเก็บไฟล์ขนาด 4 GiB ได้ โปรดใช้ไดรฟ์ NTFS หรือ exFAT |

### หน้าจอเมื่อสร้างเสร็จ

| สิ่งที่คุณเห็น | สิ่งที่ควรทำ |
| --- | --- |
| “สร้างตัวติดตั้งแล้ว แต่มีไฟล์ 2 ไฟล์ที่หายไปหลังจากตรวจดูแอป” | คลิก **ตรวจดูอีกครั้ง** แล้วคลิก **สร้างตัวติดตั้งอีกครั้ง** หากไฟล์เหล่านั้นสำคัญ |
| “สร้างตัวติดตั้งแล้ว แต่ไม่สามารถเก็บไฟล์ 2 ไฟล์ได้ ซึ่งมักเป็นเพราะไฟล์ถูกล็อกหรืออ่านไม่ได้” | ปิดแอปและสิ่งอื่นที่กำลังใช้ไฟล์ของแอป แล้วสร้างอีกครั้ง **คำเตือน** จะแสดงว่าเป็นไฟล์ใด |
| “สร้างตัวติดตั้งแล้ว แต่ตัวติดตั้งยังมีข้อมูลบางอย่าง ที่บอกว่ามาจากใคร” | อ่านข้อความสีเหลืองอำพันด้านล่าง โปรดดู[การตรวจดูครั้งสุดท้าย](Building-an-Installer#the-last-look) |
| **คำเตือน** แสดง “ไม่สามารถดาวน์โหลด” รันไทม์ “ได้” และ “ตัวติดตั้งจะลองใช้ winget บนเครื่องเป้าหมาย” | รันไทม์นั้นไม่ได้อยู่ในตัวติดตั้ง พีซีเครื่องใหม่จึงต้องใช้อินเทอร์เน็ตสำหรับรันไทม์นั้น โปรดสร้างอีกครั้งขณะออนไลน์ โปรดดู[รันไทม์](Runtimes#at-build-time) |
| “อย่าใช้ตัวติดตั้งนี้: ตัวติดตั้งไม่ผ่านการตรวจสอบแฮช” | อย่าใช้ตัวติดตั้งนั้น โปรดสร้างอีกครั้ง หากเกิดขึ้นอีก ไดรฟ์อาจกำลังจะเสีย |
| “เขียนตัวติดตั้งแล้ว แต่ไม่สามารถตรวจสอบแฮชได้” | อย่าใช้ตัวติดตั้งนั้น โปรดสร้างอีกครั้ง |
| “ยกเลิกการสร้างแล้ว ไม่มีการเขียนตัวติดตั้ง” | คุณคลิก **ยกเลิก** |
| “ไม่สามารถสร้างตัวติดตั้งได้” ตามด้วยเหตุผล | อ่านเหตุผล **คัดลอกข้อผิดพลาด** จะคัดลอกเหตุผลนั้น และ **ไฟล์บันทึก** จะแสดงตำแหน่งของไฟล์บันทึก |
| “ไม่สามารถสร้างโฟลเดอร์ผลลัพธ์” | เลือกโฟลเดอร์ที่คุณเขียนได้ |
| “ไม่สามารถสร้างโฟลเดอร์พักไฟล์ที่ได้รับการป้องกัน จึงไม่มีการสร้างสิ่งใด” | การสร้างไม่สามารถสร้างโฟลเดอร์ทำงานส่วนตัวไว้ข้างโฟลเดอร์ผลลัพธ์ หรือในโฟลเดอร์ชั่วคราวของ Windows ได้ โปรดเลือกโฟลเดอร์ผลลัพธ์บนไดรฟ์อื่น |
| “การสร้างหยุดลงโดยไม่คาดคิด” | เกิดสิ่งผิดพลาดที่ไม่มีใครคาดคิด “หากมีตัวติดตั้งเหลืออยู่ในโฟลเดอร์ผลลัพธ์ อย่าใช้ตัวติดตั้งนั้น” โปรด[รายงานปัญหา](#getting-help) |

<a id="installing"></a>

## การติดตั้ง

<a id="when-the-installer-opens"></a>

### เมื่อเปิดตัวติดตั้ง

| สิ่งที่คุณเห็น | ความหมาย | สิ่งที่ควรทำ |
| --- | --- | --- |
| “กำลังตรวจสอบตัวติดตั้ง…” เป็นเวลานาน | ตัวติดตั้งอ่านทั้งแพคเกจเพื่อตรวจสอบแฮช | โปรดรอ ตัวติดตั้งขนาดใหญ่ใช้เวลาสักครู่ |
| “ไม่สามารถอ่านตัวติดตั้งได้:” และ “ตัวติดตั้งนี้เสียหายหรือถูกเปลี่ยนแปลง หลังจากสร้าง จึงไม่มีการอ่านสิ่งใดจากแพคเกจ โปรดคัดลอกตัวติดตั้งอีกครั้งจากที่ที่สร้างไว้” | ไฟล์ไม่ครบหรือถูกเปลี่ยนแปลง | คัดลอกอีกครั้ง |
| “ตัวติดตั้งนี้เก็บแพคเกจไว้ในไฟล์ชื่อ” ไฟล์ `.wamdata` “ในโฟลเดอร์เดียวกัน แต่ไม่มีไฟล์นั้นอยู่” | ตัวติดตั้งแบบสองไฟล์ขาดไฟล์ข้อมูล | คัดลอกไฟล์ `.wamdata` ไว้ในโฟลเดอร์เดียวกัน โปรดดู[แอปขนาดใหญ่](Big-Apps) |
| ไฟล์ข้อมูล “ไม่ใช่ไฟล์ข้อมูลของตัวติดตั้งนี้ หรือเสียหายหรือถูกเปลี่ยนแปลงหลังจากสร้าง” | ไฟล์ข้อมูลไม่ตรงกัน | คัดลอกทั้งสองไฟล์อีกครั้ง จากที่ที่สร้างไว้ |
| “ไม่สามารถใช้แพคเกจของตัวติดตั้งนี้ บนพีซีเครื่องนี้ได้:” และ “แอปนี้ไม่สามารถทำงานบนพีซีเครื่องนี้ได้ จึงไม่มีการเปลี่ยนแปลงสิ่งใด” | โปรแกรมของแอปสร้างขึ้นสำหรับโปรเซสเซอร์อื่น หรือโปรแกรมระบุว่าต้องใช้ Windows รุ่นที่ใหม่กว่า | ติดตั้งบนพีซีที่เหมือนกับเครื่องเก่า ยังไม่มีการเปลี่ยนแปลงสิ่งใด |
| “นี่คือสตับตัวติดตั้งของ WinAppMigrator ซึ่งไม่มีแพคเกจแอปพลิเคชันอยู่ภายใน” | นี่คือสตับเปล่า ไม่ใช่ตัวติดตั้งที่สร้างแล้ว | สร้างตัวติดตั้งด้วยแอป แล้วเรียกใช้ตัวติดตั้งนั้น |
| “ลายเซ็นของตัวติดตั้งนี้ไม่ถูกต้อง” พร้อมเหตุผลของ Windows | ตัวติดตั้งได้รับการลงนาม แต่ Windows ไม่ยอมรับลายเซ็น ตัวติดตั้งอาจเปลี่ยนแปลงไปหลังจากนั้น หรือใบรับรองไม่เป็นที่เชื่อถือบนพีซีเครื่องนี้ | อย่าติดตั้ง โปรดสอบถามผู้สร้าง |
| ข้อความแจ้ง UAC แสดง “ผู้เผยแพร่ที่ไม่รู้จัก” | ตัวติดตั้งไม่ได้ลงนาม ซึ่งเป็นเรื่องปกติสำหรับตัวติดตั้งที่คุณสร้างเอง | เรียกใช้เฉพาะเมื่อคุณเชื่อถือแหล่งที่มา |

<a id="the-install-location"></a>

### ตำแหน่งที่ติดตั้ง

เมื่อ **ติดตั้ง** และ **แสดงตัวอย่างการเปลี่ยนแปลง** เป็นสีเทา ประกาศสีแดงใต้ **ตำแหน่งที่ติดตั้ง** จะบอกเหตุผล สาเหตุที่พบบ่อยที่สุดคือแอปติดตั้งอยู่ในโฟลเดอร์นั้นบนพีซีเครื่องนี้แล้ว ซึ่งมักเกิดกับเว็บเบราว์เซอร์ โปรแกรมเล่นสื่อ หรือ Office: ให้ถอนการติดตั้งสำเนานั้นก่อน ในการตั้งค่า Windows ภายใต้ **แอป** แล้วเปิดตัวติดตั้งอีกครั้ง หรือพิมพ์โฟลเดอร์ใหม่ที่ว่างเปล่า เหตุผลต่างๆ และสิ่งที่ควรทำ อยู่ใน[การติดตั้งบนพีซีเครื่องใหม่](Installing-on-the-New-PC#when-the-location-cannot-be-used)

<a id="before-or-during-the-install"></a>

### ก่อนหรือระหว่างการติดตั้ง

| สิ่งที่คุณเห็น | ความหมาย | สิ่งที่ควรทำ |
| --- | --- | --- |
| “พื้นที่ที่นี่อาจไม่เพียงพอ” | ไดรฟ์ดูเหมือนมีพื้นที่ไม่พอ | เพิ่มพื้นที่ว่าง หรือเลือกตำแหน่งบนไดรฟ์อื่น |
| “พื้นที่ไม่เพียงพอ จึงไม่มีการเปลี่ยนแปลงสิ่งใด” | ไดรฟ์ที่ตัวติดตั้งเขียนข้อมูลลงไปเต็มเกินไป | เพิ่มพื้นที่ว่างบนไดรฟ์นั้น หรือเลือกตำแหน่งที่ติดตั้งบนไดรฟ์อื่น |
| “สิ่งที่ตัวติดตั้งจะทำที่นี่เปลี่ยนไปแล้ว จึงไม่มีการติดตั้งสิ่งใด” | มีบางอย่างบนพีซีเปลี่ยนไปตั้งแต่คำนวณรายการ | อ่านรายการอีกครั้ง แล้วคลิก **ติดตั้ง** อีกครั้งหากเป็นสิ่งที่คุณต้องการ |
| “การติดตั้ง” แอปหนึ่ง “ครั้งก่อนไม่เสร็จสมบูรณ์ เมื่อติดตั้ง ระบบจะเลิกทำการติดตั้งครั้งนั้นก่อน” | การติดตั้งครั้งก่อนถูกขัดจังหวะ | คลิก **ติดตั้ง** ตัวติดตั้งจะเลิกทำการติดตั้งนั้นก่อน |
| “มีการติดตั้งหรือถอนการติดตั้งอื่นกำลังทำงานอยู่ โปรดรอให้เสร็จ แล้วลองอีกครั้ง” | ทำงานได้ทีละรายการเท่านั้น | รอ แล้วลองอีกครั้ง |
| ไฟล์หนึ่ง “มีชื่อที่ Windows เวอร์ชันนี้เปิดเป็นอุปกรณ์แทนที่จะเปิดเป็นไฟล์” | แอปมีไฟล์ที่มีชื่อลักษณะเช่น `aux.h` ซึ่ง Windows ก่อน Windows 11 ไม่สามารถเก็บได้ | ติดตั้งบน Windows 11 |
| “ไม่สามารถสร้างโฟลเดอร์พักไฟล์ได้” | ไม่มีที่ส่วนตัวที่มีพื้นที่เพียงพอสำหรับแตกไฟล์แพคเกจ | เพิ่มพื้นที่ว่างบนไดรฟ์ของตำแหน่งที่ติดตั้ง หรือไดรฟ์ระบบ |
| โฟลเดอร์ข้อมูล เช่น `%AppData%` ถูกระบุว่าเป็นลิงก์ | ตัวติดตั้งจะไม่เขียนผ่าน[ลิงก์](Glossary#link) | ยกเลิกการทำเครื่องหมาย **ข้อมูลผู้ใช้** และ **สิทธิ์การใช้งาน** แล้วติดตั้งโดยไม่มีข้อมูลเหล่านั้น |
| “ไม่พบโฟลเดอร์ ProgramData ของพีซีเครื่องนี้ จึงไม่ได้ติดตั้งสิ่งใด” | ไม่สามารถอ่านบันทึกของ Windows เองว่า ProgramData อยู่ที่ใด | ตัวติดตั้งจะไม่ติดตั้ง หากไม่มีที่ปลอดภัยสำหรับเก็บบันทึกการติดตั้ง |

### ผลลัพธ์

| สิ่งที่คุณเห็น | สิ่งที่ควรทำ |
| --- | --- |
| “การติดตั้งล้มเหลว และสิ่งที่เปลี่ยนแปลงไปได้รับการย้อนกลับแล้ว” | อ่านข้อความสีแดงเพื่อดูสาเหตุ พีซีอยู่ในสภาพเดิม ยกเว้นรันไทม์ที่ติดตั้งไว้ |
| “การติดตั้งล้มเหลว และไม่สามารถย้อนกลับสิ่งที่เปลี่ยนแปลงได้ทั้งหมด” | อ่านสิ่งที่แสดงในรายการ ปิดสิ่งที่อาจกำลังใช้ไฟล์เหล่านั้น แล้วเรียกใช้ตัวติดตั้งอีกครั้ง: ตัวติดตั้งจะลองย้อนกลับอีกครั้งก่อน |
| “ไม่สามารถติดตั้ง” รันไทม์ “ได้” | ไม่สามารถติดตั้งรันไทม์ได้ การติดตั้งจึงถูกย้อนกลับ สำหรับ DirectX End-User Runtime พีซีเครื่องใหม่ต้องใช้อินเทอร์เน็ต โปรดดู[รันไทม์](Runtimes#with-no-internet-on-the-new-pc) |
| “ส่วนประกอบที่ต้องใช้รายการหนึ่ง ต้องเริ่มระบบใหม่ จึงจะเสร็จสมบูรณ์ โปรดเริ่ม Windows ใหม่ แล้วเปิดแอป” | เริ่มระบบใหม่ แล้วเริ่มแอป |
| บริการ “ทำงานในฐานะ” บัญชีหนึ่ง “บนพีซีต้นทาง รหัสผ่านของบัญชีนี้ไม่ได้อยู่ในตัวติดตั้ง จึงตั้งค่าบริการให้ทำงานในฐานะ LocalService” | เปิด “บริการ” แล้วตั้งค่าบัญชีและรหัสผ่านของบริการ หากบริการทำงานไม่ได้ตามที่เป็นอยู่ |
| ไฟล์บางไฟล์ “จะไปอยู่ภายใต้” โฟลเดอร์ที่ติดตั้ง “แทน ในโฟลเดอร์ชื่อ _external” | พีซีเครื่องนี้เก็บเอกสารหรือเกมที่บันทึกไว้นอกโปรไฟล์ของคุณ โปรดย้ายไฟล์เหล่านั้นไปยังโฟลเดอร์นั้นด้วยตนเอง |
| บางสิ่ง “ไม่ได้รวมไว้” พร้อมเหตุผล | กฎปฏิเสธสิ่งนั้น หรือสิ่งนั้นเป็นของแอปอื่นที่นี่อยู่แล้ว ส่วนที่เหลือติดตั้งแล้ว หากแอปต้องใช้สิ่งนั้น โปรดดูเหตุผล |
| **แฮชของแพคเกจไม่ถูกต้อง** หรือ **ไฟล์ที่ติดตั้งไม่ถูกต้อง** | มีบางอย่างไม่ตรงกัน โปรดคัดลอกตัวติดตั้งอีกครั้ง แล้วลองอีกครั้ง |

### หลังจากติดตั้ง

| สิ่งที่คุณเห็น | สิ่งที่ควรทำ |
| --- | --- |
| แอปไม่เริ่มทำงาน | ตรวจสอบ **ส่วนประกอบที่ต้องใช้** ว่ามีรันไทม์ที่มีป้ายกำกับ **ติดตั้งด้วยตนเอง** หรือไม่ แล้วติดตั้งรันไทม์นั้น และตรวจสอบคำเตือนในผลลัพธ์ |
| แอปจาก Windows 7 ไม่เริ่มทำงาน และคำเตือนตอนสร้างระบุ DLL ที่ “Windows 10 และ 11 ไม่มีไฟล์นี้มาให้” | DLL นั้นถูกวางไว้ในโฟลเดอร์ของ Windows เครื่องเก่าโดยสิ่งอื่น จึงไม่ได้ถูกนำมาด้วย โปรดติดตั้งสิ่งที่จัดหา DLL นั้น แล้วเริ่มแอปอีกครั้ง โปรดดู[แอปจาก Windows 7, Vista, 8 หรือ 8.1](Moving-from-a-Connected-Drive#apps-from-windows-7-vista-8-or-81) |
| แอปเริ่มทำงานเหมือนเพิ่งติดตั้งใหม่ | เป็นเรื่องปกติกับตัวติดตั้งที่สร้างโดยปิด **ข้อมูลผู้ใช้** ไว้ และยังเกิดขึ้นเมื่อยกเลิกการทำเครื่องหมาย **ข้อมูลผู้ใช้** ตอนติดตั้ง เพราะข้อมูลจะไปอยู่ภายใต้โฟลเดอร์ที่ติดตั้ง รวมถึงเมื่อตัวติดตั้งไม่สามารถทราบได้ว่าใครลงชื่อเข้าใช้อยู่ ซึ่งตัวติดตั้งจะแจ้งให้ทราบ |
| แอปขอให้เปิดใช้งาน | สิทธิ์การใช้งานที่ผูกกับพีซีเครื่องเก่าต้องเปิดใช้งานอีกครั้ง |
| ตัวอัปเดตของแอปเองคิดว่าแอปไม่ได้ติดตั้งอยู่ | Windows Installer ไม่มีบันทึกของแอปที่นี่ โปรดดู[ข้อจำกัด](Limitations) |
| ชนิดไฟล์หรือชนิดลิงก์ไม่เปิดด้วยแอป | แอปอื่นเป็นเจ้าของอยู่แล้วที่นี่ จึงถูกปล่อยไว้ตามเดิม โปรดเลือกแอปในการตั้งค่า ภายใต้ “แอปเริ่มต้น” |
| ไม่พบรายการ `Path` ใหม่ | เปิด PowerShell หรือพร้อมท์คำสั่งใหม่ บางโปรแกรมจะเห็นการเปลี่ยนแปลงหลังจากคุณลงชื่อออก แล้วลงชื่อเข้าใช้อีกครั้งเท่านั้น |

<a id="uninstalling"></a>

## การถอนการติดตั้ง

| สิ่งที่คุณเห็น | สิ่งที่ควรทำ |
| --- | --- |
| “บางส่วนอยู่บนไดรฟ์ที่ไม่ได้เชื่อมต่ออยู่” | เชื่อมต่อไดรฟ์นั้น แล้วถอนการติดตั้งอีกครั้งจากการตั้งค่า |
| “ไม่สามารถเลิกทำได้ทั้งหมด โปรดปิดสิ่งที่กำลังใช้งานอยู่ แล้วถอนการติดตั้งอีกครั้งจากการตั้งค่า” | ปิดแอปและสิ่งที่กำลังใช้ไฟล์ของแอป หากบริการไม่หยุด ให้เริ่มพีซีใหม่ จากนั้นถอนการติดตั้งอีกครั้ง |
| “this is not an install's id” (บรรทัดคำสั่งแสดงเป็นภาษาอังกฤษ) | รหัสที่ให้กับ `--uninstall` ไม่ถูกต้อง โปรดคัดลอกจากรายการในการตั้งค่า โปรดดู[บรรทัดคำสั่ง](Command-Line#finding-the-id) |
| มีไฟล์ชื่อ `.before-install` ปรากฏขึ้น | เป็นต้นฉบับของไฟล์ที่การติดตั้งแทนที่ ซึ่งคุณได้เปลี่ยนแปลงไว้ตั้งแต่นั้น โปรดเก็บไฟล์ที่คุณต้องการ |
| รันไทม์ยังคงติดตั้งอยู่ | รันไทม์จะยังคงอยู่ เนื่องจากโปรแกรมอื่นอาจใช้งาน ให้ปล่อยไว้ เว้นแต่คุณแน่ใจว่าไม่มีสิ่งอื่นใช้งาน |

<a id="language-and-text"></a>

## ภาษาและข้อความ

- **ภาษาไม่ถูกต้อง** เลือกภาษาอื่นภายใต้ **ภาษา** ที่มุมขวาบนของแอป หรือของหน้าจอแรกของตัวติดตั้ง แอปจะจดจำภาษาที่เลือก ส่วนตัวติดตั้งจะใช้ภาษานั้นสำหรับการเรียกใช้ครั้งนั้น หากไม่ได้เลือก ทั้งสองโปรแกรมจะใช้ภาษาแรกในภาษาที่ใช้แสดงของ Windows ที่โปรแกรมมี มิฉะนั้นจะใช้ภาษาอังกฤษ
- **คำแปลอ่านแล้วไม่ถูกต้อง** ทุกภาษายกเว้นภาษาอังกฤษแปลด้วยเครื่อง ภายใต้ **ภาษา** ให้เลือก **รายงานปัญหาการแปล** ซึ่งจะเปิดแบบฟอร์มที่กรอกภาษาของคุณไว้แล้ว โปรดระบุว่าหน้าจอแสดงอะไร และควรแสดงว่าอะไร
- **ตัวอักษรแสดงเป็นกล่องว่าง** หน้าต่างใช้ฟอนต์ที่มาพร้อมกับ Windows สำหรับแต่ละระบบการเขียน จาก `C:\Windows\Fonts` Windows ที่ถูกลบฟอนต์บางตัวออกจะแสดงตัวอักษรเหล่านั้นเป็นกล่อง และชื่อของแอปอื่นในรายการก็อาจต้องใช้ฟอนต์เหล่านั้นด้วย
- **คำถูกตัด** ป้ายกำกับที่ยาวเกินพื้นที่จะลงท้ายด้วย `…` ให้วางเมาส์เหนือป้ายกำกับนั้น หรือเลื่อนไปที่ป้ายกำกับด้วยแป้น Tab เพื่อดูข้อความทั้งหมด โปรดรายงานพร้อมระบุภาษาและหน้าจอ เพื่อให้ปรับหน้าต่างให้พอดีได้
- **WinAppMigrator Client แสดงภาษาอังกฤษบน Windows ที่เขียนจากขวาไปซ้าย** คอนโซลที่ไคลเอ็นต์ทำงานอยู่ไม่สามารถเชื่อมหรือเรียงตัวอักษรอาหรับหรือฮีบรูได้ ไคลเอ็นต์จึงแสดงภาษาอังกฤษ และบอกเหตุผล `--lang` ใช้เลือกภาษาใดก็ได้ที่ไคลเอ็นต์มี

<a id="getting-help"></a>

## การขอความช่วยเหลือ

1. ค้นหา[ไฟล์บันทึก](Glossary#log) เส้นทางของไฟล์จะแสดงเป็น **ไฟล์บันทึก** เมื่อเกิดความล้มเหลว หรือพิมพ์เป็น `Log:` จากบรรทัดคำสั่ง ไฟล์บันทึกอยู่ใน `%ProgramData%\WinAppMigrator\logs` ไฟล์เหล่านี้เก็บเส้นทางและชื่อคีย์ และไม่เคยเก็บสิ่งที่อยู่ในการตั้งค่า ไฟล์สิทธิ์การใช้งาน หรือตัวแปรสภาพแวดล้อม แต่ยังอาจมีชื่อโฟลเดอร์ของคุณ โปรดอ่านก่อนแชร์
2. [เปิดปัญหา (issue)](https://github.com/RandyNorthrup/WinAppMigrator/issues) พร้อมระบุเวอร์ชัน สิ่งที่คุณทำ และสิ่งที่หน้าจอแสดง **คัดลอกข้อผิดพลาด** บนหน้าจอเมื่อสร้างเสร็จของแอปจะคัดลอกข้อความให้
3. **อย่าแนบตัวติดตั้งไปกับ issue เด็ดขาด** ตัวติดตั้งอาจมีข้อมูลส่วนตัว
4. สำหรับปัญหาด้านความปลอดภัย โปรดรายงานแบบส่วนตัวแทน ผ่าน[คำแนะนำด้านความปลอดภัยของ GitHub](https://github.com/RandyNorthrup/WinAppMigrator/security/advisories/new)
