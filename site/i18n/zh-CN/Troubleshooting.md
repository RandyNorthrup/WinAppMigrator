# 疑难解答

请根据发生的情况或屏幕上的文字，在下面找到你看到的内容。引号中的文字是程序显示的内容，有时中间会插入名称或数字。

如果这里的内容都没有帮助，请参阅末尾的[获取帮助](#getting-help)。

<a id="the-window-could-not-open"></a>

## 无法打开窗口

**你看到的内容**。出现一个消息框，而不是窗口：

- 来自应用：“无法打开窗口”，以及“此程序需要 Direct3D 12 来绘制窗口，而旧版显卡驱动程序或虚拟机可能不支持它。”
- 来自安装程序：相同的内容，以及“没有窗口也可以安装：在管理员命令提示符中使用 --apply 运行此文件；若要选择安装位置，请再加上 --target-root，后跟一个文件夹。”
- 来自卸载程序：相同的内容，以及“没有窗口也可以卸载，在管理员命令提示符中运行：”，后面是确切的命令。

**原因**。这些窗口是用 [Direct3D 12](Glossary#direct3d-12) 绘制的，没有其他方式可以绘制它们。

**处理方法**。

- 更新电脑的显卡驱动程序。
- 对于安装程序或卸载程序，请使用命令行。请参阅[命令行](Command-Line)。
- WinAppMigrator 应用本身没有命令行。请在另一台电脑上生成：你可以将旧电脑的驱动器连接到那台电脑。请参阅[从已连接的驱动器迁移](Moving-from-a-Connected-Drive)。那台电脑也可以通过网络读取旧电脑。请参阅[通过网络从电脑迁移](Moving-over-the-Network)。

<a id="starting-the-app"></a>

## 启动应用

| 你看到的内容 | 含义 | 处理方法 |
| --- | --- | --- |
| 应用的 UAC 提示显示“未知发布者” | 从 0.5.0 起，应用已签名。未签名的应用不是发布文件，或者来自 0.5.0 之前的版本。 | 从[最新版本](https://github.com/RandyNorthrup/WinAppMigrator/releases/latest)重新下载，并[检查它](Getting-Started#check-the-download)。 |
| SmartScreen 显示“Windows 已保护你的电脑” | SmartScreen 不常见到该文件 | 选择**更多信息**，确认发布者是 Randy Northrup，然后选择**仍要运行**。 |
| 顶部的标签显示**加载失败**，列表显示“无法列出应用” | 无法读取应用列表 | 单击圆形箭头重新加载。对于已连接的驱动器，请检查它是否仍处于连接状态。 |
| 列表中没有你想要的应用 | 它是 Microsoft Store 应用、另一个应用的隐藏部分，或者在“设置”中根本没有条目，例如便携式应用 | Store 应用无法迁移。选择主应用时，隐藏部分可能会出现在**可能也属于此应用**下。在“设置”中没有条目的应用无法选择。 |
| “没有匹配的应用” | 搜索或筛选器隐藏了所有内容 | 清除搜索框，然后选择**全部**。 |

## 生成

<a id="picking-a-drive-or-a-disk-image"></a>

### 选择驱动器或磁盘映像

| 你看到的内容 | 处理方法 |
| --- | --- |
| 驱动器“看起来不像 Windows 系统驱动器（没有 \Windows 和 \Users）。请选择来自另一台电脑的驱动器的根目录。” | 选择驱动器的顶层，例如 `E:\`，而不是其中的文件夹。检查它是否是安装了 Windows 的那个驱动器。 |
| 映像“不是 Windows 可以附加的磁盘映像 (.vhd 或 .vhdx)” | 选择 `.vhd` 或 `.vhdx`。请先将 VMware 或 VirtualBox 磁盘另存为其中一种格式。对于 Hyper-V 检查点 `.avhdx`，请导出虚拟机的磁盘。 |
| “无法附加”映像：“Windows 已附加此映像，附加它的程序可能正在向其写入。” | 它在其他地方处于打开状态，例如在文件资源管理器中被装载。请改为选择它的驱动器（使用**已连接的驱动器…**），或者将它分离，然后重新选择。 |
| 映像“中没有可读取的装有 Windows 的卷。使用 BitLocker 加密的卷必须先解锁。” | 检查它是否是安装了 Windows 的驱动器的映像。如果它被 [BitLocker](Glossary#bitlocker) 锁定，请自己在 Windows 中装载并解锁它，然后选择它的驱动器（使用**已连接的驱动器…**）。 |
| 映像“是差异磁盘，只包含自其父磁盘创建以来的更改” | 使用 Hyper-V 的“编辑磁盘”将其合并到父磁盘中，然后选择父磁盘。 |
| “无法附加”映像，以及其他原因 | 该原因由 Windows 给出。请阅读原因，检查是否有其他程序正在使用该映像，然后重试。 |

<a id="reading-a-pc-over-the-network"></a>

### 通过网络读取电脑

完整的列表，包括客户端在旧电脑上显示的内容，请参阅[通过网络从电脑迁移](Moving-over-the-Network#if-something-goes-wrong)。

| 你看到的内容 | 处理方法 |
| --- | --- |
| 旧电脑没有列在**2. 选择旧电脑**下 | 检查客户端是否正在旧电脑上运行并显示代码，以及两台电脑是否在同一网络中。然后输入它的名称或地址。如果中间隔着路由器，请输入它的地址。Windows 自带防火墙以外的防火墙必须允许 TCP 47732 和 UDP 47731 通过。 |
| “在网络上找不到”某个名称 | 改为输入旧电脑的地址。 |
| “无法连接到旧电脑：”及原因 | 检查客户端是否仍在运行，以及名称或地址是否正确。 |
| “这不是旧电脑显示的代码。请检查后重试。” | 输入客户端当前显示的代码。输错五次后，它会生成新的代码。输错 20 次后，在你重新启动它之前，它不允许任何配对。 |
| 在旧电脑上，Windows 显示客户端的发布者未知 | 只有在没有 Microsoft 2020 根证书的 Windows 7 上才应出现这种情况，因为它无法检查客户端的签名。在那里，只有对你自己从应用中保存的客户端才选择**是**。在其他任何地方，提示都应显示 Randy Northrup。如果没有显示，请不要运行该副本。 |
| 长时间暂停后，应用无法再读取旧电脑 | 如果应用 30 分钟没有向客户端请求任何内容，客户端会结束该连接。单击**断开连接**，然后重新配对。 |

<a id="looking-at-the-app"></a>

### 查看应用

| 你看到的内容 | 含义 | 处理方法 |
| --- | --- | --- |
| “无法查看此应用”及原因 | 查看失败。一个常见原因是某个条目根本没有对应的程序，例如驱动程序包。 | 单击**重试**。如果以同样的方式失败，该条目可能不是 WinAppMigrator 能迁移的应用。 |
| “已停止。查看完此应用后才能生成安装程序。” | 你单击了**停止** | 单击**重新查看**。 |
| 查看需要很长时间 | 应用很大、驱动器速度慢或即将损坏，或者帐户很多 | 如果驱动器可能即将损坏，请单击**停止**，为它创建[磁盘映像](Glossary#disk-image)，然后改为选择该映像，因为读取即将损坏的驱动器可能会让它彻底报废。从 0.6.0 起，选择映像时请使用**磁盘映像…**。在 0.5.0 中，请装载映像并选择其驱动器。否则，请等待。在此期间你可以选择另一个应用。 |
| 你想要的某一行显示为灰色且已勾选 | 它包含主程序，或主程序启动所需的内容 | 它始终会包含在内。请参阅[无法取消勾选的行](Building-an-Installer#the-groups)。 |
| 某一行显示“也已排除：” | 你取消勾选的某项内容连带排除了它 | 如果你需要它，请重新勾选那项内容。 |
| “剩余的内容无法构成程序包” | 你取消勾选的内容使剩下的内容无法生成 | 重新勾选某些内容。 |
| “你排除的内容中的许可证数据仍会包含在内” | 许可证只由**许可证和激活数据**选项决定 | 如果你想排除它们，请取消勾选该选项。 |

<a id="create-installer-stays-greyed-out"></a>

### “创建安装程序”一直显示为灰色

在以下条件全部满足之前，它会一直等待：

- 已按当前的选项完成对应用的查看（“正在确定与之相关的内容…”表示它仍在确定你最后一次取消勾选会连带排除哪些内容）；
- **输出文件夹**是完整路径，例如 `D:\Installers`（“请输入完整的文件夹路径，例如 D:\Installers。”）；
- 该驱动器上有足够的空间。

<a id="room"></a>

### 空间

| 你看到的内容 | 处理方法 |
| --- | --- |
| “空间不足。”以及某个驱动器需要多少空间、有多少空间 | 选择其他驱动器上的输出文件夹，或排除某些内容。这个数字是生成可能占用的最大空间（压缩之前），因此可能比安装程序实际的大小更大。 |
| 某个驱动器“未报告其可用空间” | 生成会继续进行，但不检查该驱动器。请确保它有足够的空间。 |
| FAT32 驱动器和大型应用 | FAT32 无法保存 4 GiB 的文件。请使用 NTFS 或 exFAT 驱动器。 |

<a id="the-done-screen"></a>

### 完成屏幕

| 你看到的内容 | 处理方法 |
| --- | --- |
| “安装程序已生成，但自查看此应用以来已有”若干“个文件不复存在” | 如果这些文件很重要，请单击**重新查看**，然后单击**再次创建安装程序**。 |
| “安装程序已生成，但有”若干“个文件无法捕获，通常是因为它们被锁定或无法读取。” | 关闭该应用以及其他正在使用其文件的程序，然后重新生成。**警告**会列出是哪些文件。 |
| “安装程序已生成，但其中仍包含有关其来源的信息。” | 请阅读其下方的琥珀色消息。请参阅[最后一次检查](Building-an-Installer#the-last-look)。 |
| **警告**显示“无法下载”某个运行时，以及“安装程序将在目标电脑上尝试使用 winget。” | 该运行时不在安装程序中，因此新电脑需要联网才能获得它。请在联网时重新生成。请参阅[运行时](Runtimes#at-build-time)。 |
| “请不要使用此安装程序：它未通过哈希检查。” | 不要使用它。请重新生成。如果再次发生，驱动器可能即将损坏。 |
| “安装程序已写入，但无法运行其哈希检查” | 不要使用它。请重新生成。 |
| “已取消生成。未写入任何安装程序。” | 你单击了**取消**。 |
| “无法生成安装程序。”及原因 | 请阅读原因。**复制错误信息**会复制它，**日志**会显示日志的位置。 |
| “无法创建输出文件夹” | 选择一个你可以写入的文件夹。 |
| “无法创建受保护的暂存文件夹，因此未生成任何内容” | 生成过程无法在输出文件夹旁边或 Windows 的临时文件夹中创建其专用的工作文件夹。请选择其他驱动器上的输出文件夹。 |
| “生成意外停止” | 发生了谁都没有预料到的问题。“如果它在输出文件夹中留下了安装程序，请不要使用该安装程序。”请[报告此问题](#getting-help)。 |

<a id="installing"></a>

## 安装

<a id="when-the-installer-opens"></a>

### 安装程序打开时

| 你看到的内容 | 含义 | 处理方法 |
| --- | --- | --- |
| 长时间显示“正在检查安装程序…” | 它会读取整个程序包来检查哈希 | 请等待。大型安装程序需要一段时间。 |
| “无法读取安装程序：”以及“此安装程序已损坏，或在生成后被更改，因此未从其程序包中读取任何内容。请从生成它的位置重新复制。” | 文件被截断或已被更改 | 重新复制。 |
| “此安装程序将其程序包保存在同一文件夹中名为”某个 `.wamdata` 文件“的文件中，但该文件不存在” | 由两个文件组成的安装程序缺少数据文件 | 将 `.wamdata` 文件复制到同一个文件夹中。请参阅[大型应用](Big-Apps)。 |
| 数据文件“不是此安装程序的数据文件，或者已损坏，或在生成后被更改” | 数据文件不匹配 | 从生成它们的位置重新复制这两个文件。 |
| “此安装程序的程序包无法在此电脑上使用：”以及“此应用无法在此电脑上运行，因此未进行任何更改” | 应用的程序是为另一种处理器生成的，或者某个程序表明它需要较新版本的 Windows | 在与旧电脑类似的电脑上安装。没有进行任何更改。 |
| “这是 WinAppMigrator 安装程序存根，其中不包含任何应用的程序包。” | 这是单纯的存根，而不是生成的安装程序 | 使用 WinAppMigrator 生成安装程序，然后运行生成的安装程序。 |
| “此安装程序的签名无效”，以及 Windows 给出的原因 | 它已签名，但 Windows 不接受该签名。它可能在签名后被更改过，或者其证书在此电脑上不受信任。 | 不要安装它。请向生成它的人核实。 |
| UAC 提示显示“未知发布者” | 安装程序未签名。对于你自己生成的安装程序，这是正常的。 | 只有在你信任其来源时才运行它。 |

<a id="the-install-location"></a>

### 安装位置

如果**安装**和**预览更改**显示为灰色，**安装位置**下方的红色通知会说明原因。最常见的原因是该应用已经安装在此电脑上的那个文件夹中，Web 浏览器、媒体播放器或 Office 经常如此：请先在 Windows 设置的**应用**中卸载那个副本，然后重新打开安装程序，或者输入一个新的空文件夹。各种原因以及处理方法，请参阅[在新电脑上安装](Installing-on-the-New-PC#when-the-location-cannot-be-used)。

<a id="before-or-during-the-install"></a>

### 安装之前或安装期间

| 你看到的内容 | 含义 | 处理方法 |
| --- | --- | --- |
| “此处可能没有足够的空间” | 驱动器的空间看起来不足 | 释放空间，或选择其他驱动器上的位置。 |
| “空间不足，因此未进行任何更改” | 它要写入的某个驱动器太满 | 在该驱动器上释放空间，或选择其他驱动器上的安装位置。 |
| “在此处将执行的操作已发生变化，因此未安装任何内容。” | 自确定列表以来，电脑上的某些内容发生了变化 | 重新阅读列表，如果符合你的要求，请再次单击**安装**。 |
| 某个应用“之前的一次安装未完成。安装时会先撤消该次安装。” | 之前的一次安装被中断 | 单击**安装**。它会先撤消那次安装。 |
| “另一个安装或卸载正在运行。请等待它完成后重试” | 一次只能运行一个 | 请等待，然后重试。 |
| 某个文件“的名称会被此版本的 Windows 当作设备而不是文件打开” | 应用中有名为 `aux.h` 之类的文件，Windows 11 之前的 Windows 无法保存这种文件 | 在 Windows 11 上安装。 |
| “无法创建暂存文件夹” | 没有可用于解压缩程序包、有足够空间的专用位置 | 在安装位置所在的驱动器或系统驱动器上释放空间。 |
| 提示某个数据文件夹（例如 `%AppData%`）是链接 | 安装程序不会通过[链接](Glossary#link)写入 | 取消勾选**用户数据**和**许可证**，然后在不包含它们的情况下安装。 |
| “找不到此电脑的 ProgramData 文件夹，因此未安装任何内容” | 无法读取 Windows 自己记录的 ProgramData 位置 | 如果没有安全的地方保存其记录，安装程序就不会安装。 |

<a id="the-result"></a>

### 结果

| 你看到的内容 | 处理方法 |
| --- | --- |
| “安装失败，其所做的更改已恢复。” | 请阅读红色消息了解原因。电脑已恢复原状，但它安装的运行时除外。 |
| “安装失败，且其所做的更改未能全部恢复。” | 阅读列出的内容。关闭可能正在使用这些文件的程序，然后运行一个安装程序：它会先再次尝试恢复。 |
| “无法安装”某个运行时 | 该运行时无法安装，因此安装已被恢复。对于 DirectX End-User Runtime，新电脑需要联网。请参阅[运行时](Runtimes#with-no-internet-on-the-new-pc)。 |
| “某个依赖项需要重启才能完成。请重启 Windows，然后启动应用。” | 重启，然后启动应用。 |
| 服务“在源电脑上以”某个帐户“身份运行。其密码不在安装程序中，因此该服务设置为以 LocalService 身份运行。” | 如果服务按现状无法正常工作，请打开“服务”，设置该服务的帐户和密码。 |
| 有些文件“将改为放在”安装文件夹“下名为 _external 的文件夹中” | 此电脑将“文档”或“保存的游戏”保存在你的配置文件之外。请自行将这些文件移到那个文件夹。 |
| 某项内容“已被排除”，并附有原因 | 规则拒绝了它，或者它在这里已经属于其他应用。其余内容已安装。如果应用需要它，请查看原因。 |
| **程序包哈希无效**或**已安装的文件无效** | 有内容不匹配。重新复制安装程序，然后再试一次。 |

<a id="after-installing"></a>

### 安装之后

| 你看到的内容 | 处理方法 |
| --- | --- |
| 应用无法启动 | 检查**依赖项**中是否有标记为**手动安装**的运行时，如果有，请安装它。检查结果中的警告。 |
| 来自 Windows 7 的应用无法启动，并且生成时有一条警告提到某个 DLL“Windows 10 和 11 不自带” | 该 DLL 是由其他程序放入旧 Windows 自己的文件夹中的，因此没有一起迁移过来。请安装提供它的程序，然后再次启动应用。请参阅[来自 Windows 7、Vista、8 或 8.1 的应用](Moving-from-a-Connected-Drive#apps-from-windows-7-vista-8-or-81)。 |
| 应用像全新安装一样启动 | 对于在**用户数据**关闭的情况下生成的安装程序，这是正常的。在安装时取消勾选**用户数据**也会出现这种情况，因为此时数据会放在安装文件夹下；当安装程序无法确定登录的是谁时也会如此，它会说明这一点。 |
| 应用要求激活 | 与旧电脑绑定的许可证需要重新激活。 |
| 应用自己的更新程序认为它没有安装 | Windows Installer 在这里没有它的记录。请参阅[限制](Limitations)。 |
| 文件类型或链接类型不使用此应用打开 | 这里已有另一个应用拥有它，因此它保持不变。请在“设置”的“默认应用”中选择此应用。 |
| 看不到新的 `Path` 条目 | 打开一个新的 PowerShell 或命令提示符窗口。有些程序只有在你注销并重新登录后才能看到更改。 |

<a id="uninstalling"></a>

## 卸载

| 你看到的内容 | 处理方法 |
| --- | --- |
| “部分内容位于未连接的驱动器上。” | 连接该驱动器，然后从“设置”再次卸载。 |
| “并非所有内容都能撤消。请关闭正在使用它的程序，然后从‘设置’再次卸载。” | 关闭该应用以及任何正在使用其文件的程序。如果某个服务无法停止，请重启电脑。然后再次卸载。 |
| “this is not an install's id” | 传给 `--uninstall` 的 ID 不正确。请从“设置”中的条目复制它。请参阅[命令行](Command-Line#finding-the-id)。 |
| 出现了一个名为 `.before-install` 的文件 | 它是安装时被替换的某个文件的原始版本，而你此后又更改过该文件。保留你想要的那个即可。 |
| 某个运行时仍处于安装状态 | 运行时会保留，因为其他程序可能会使用它们。除非你确定没有其他程序使用它，否则请保留它。 |

<a id="scripts"></a>

## 脚本

| 你看到的内容 | 处理方法 |
| --- | --- |
| “请求的操作需要提升” | 以管理员身份运行 PowerShell。 |
| 没有任何输出，并且未设置 `$LASTEXITCODE` | 通过管道传送安装程序的输出，例如传给 `Out-String`。请参阅[命令行](Command-Line)。 |
| 退出代码 `2` | 某个标志有误，或者同时使用了 `--apply` 和 `--dry-run`。 |
| “this package does not say where its app was, so give a --target-root” | 添加 `--target-root` 和一个完整路径。 |
| 应用“was in”某个文件夹，“and that cannot be used” | 添加 `--target-root` 和另一个文件夹。 |
| 某个文件夹“cannot be used: it already has files”“Give --force only if you know it is this app's” | 选择一个空文件夹。只有对你确定属于此应用的文件夹，才使用 `--force`。 |

<a id="language-and-text"></a>

## 语言和文字

- **语言不对**。在应用或安装程序第一个屏幕的右上方，从**语言**中选择另一种语言。应用会记住你的选择；安装程序只在本次运行中保留该选择。如果没有做出选择，每个程序会使用 Windows 显示语言中它所支持的第一种语言，否则使用英语。
- **译文读起来不对**。除英语外，所有语言都由机器翻译。在**语言**下选择**报告翻译问题**，这会打开一个已填好你的语言的表单。请说明屏幕上显示的内容以及应当显示的内容。
- **字母显示为空白方框**。窗口使用 Windows 为每种文字自带的字体，位于 `C:\Windows\Fonts`。如果 Windows 删除了其中一些字体，就会把相应的字母显示为方框；列表中其他应用的名称也可能需要这些字体。
- **文字被截断**。放不下的标签会以 `…` 结尾；将鼠标悬停在上面，或使用 Tab 键移到它上面，即可看到完整内容。请报告这个问题，并说明语言和屏幕，以便调整窗口使其放得下。
- **WinAppMigrator Client 在从右到左的 Windows 上输出英语**。它运行所在的控制台无法连接或排列阿拉伯语或希伯来语字母，因此它输出英语并说明原因。`--lang` 可以选择它支持的任何语言。

<a id="getting-help"></a>

## 获取帮助

1. 找到[日志](Glossary#log)。失败时，其路径会以**日志**显示，从命令行运行时则以 `Log:` 输出。日志位于 `%ProgramData%\WinAppMigrator\logs`。日志包含路径和注册表项名称，但绝不包含设置、许可证文件或环境变量的内容。不过，日志中仍可能包含你的文件夹名称，因此在分享之前请先阅读一遍。
2. [提交问题](https://github.com/RandyNorthrup/WinAppMigrator/issues)，并附上版本、你所做的操作以及屏幕上显示的内容。应用完成屏幕上的**复制错误信息**可以复制消息。
3. **绝不要将安装程序附加到问题中**。它可能包含私人数据。
4. 如果是安全问题，请改为通过 [GitHub 的安全公告](https://github.com/RandyNorthrup/WinAppMigrator/security/advisories/new)私下报告。
