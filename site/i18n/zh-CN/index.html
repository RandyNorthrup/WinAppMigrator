将已安装的 Windows 程序迁移到新电脑

WinAppMigrator 可将一台 Windows 电脑上安装的应用转换为一个安装程序，供你在另一台电脑上运行。即使该应用位于网络中另一台旧的 Windows 7 电脑上、从即将损坏的电脑中取出的驱动器上或这种驱动器的映像中，而且原始安装程序早已不见，也同样可以。

免费开源，MIT 许可证 · Windows 10 和 11，x64 · 24 种语言 · 由 Randy Northrup 签名

适用场景

迁移到新电脑

应用随之迁移，你无需四处寻找它的安装文件、许可证文件或设置。

入门

旧电脑无法启动

取出它的驱动器，连接到一台能正常工作的电脑，然后从其中的某个应用生成安装程序。如果驱动器可能即将损坏，请先为它创建映像，再从映像生成，因为读取即将损坏的驱动器可能会让它彻底报废。

从驱动器或磁盘映像迁移

告别 Windows 7、Vista、8 或 8.1

这些系统上的应用可以迁移到 Windows 10 或 11，旧系统的不同之处也会一并处理：32 位 Windows、VirtualStore 以及 DirectX 9 运行时。

来自旧版 Windows 的应用

旧电脑仍能运行，且在你的网络中

在旧电脑上运行小巧且已签名的 WinAppMigrator Client，输入它显示的代码，然后选择一个应用。只有生成所需的内容才会通过网络传输，并且经过加密。无需从电脑中拆出任何东西。

通过网络从电脑迁移

安装文件不见了，或者公司已经不在了

它从已安装的内容反向推导：应用的文件、注册表项、服务，以及它需要的 Microsoft 运行时。

工作原理

在多台电脑上安装同一个应用

它生成的安装程序可以在命令提示符中预览、安装和卸载，因此可以用脚本在每台电脑上安装同一个应用。

命令行

工作原理

  1. 选择应用

    应用可以来自此电脑、插入此电脑的另一台电脑的驱动器、WinAppMigrator 以只读方式附加的 .vhd 或 .vhdx 映像，或网络中的另一台电脑。

  2. 查看包含的内容

    屏幕会显示安装程序最大可能有多大、空间是否够用，以及其中包含哪些内容。取消勾选你不需要的内容，并勾选按确切名称没有找到、但看起来相关的内容。

  3. 生成安装程序

    你会得到一个 .exe，以其中包含的内容命名。对于一个文件装不下的大型应用，会生成一个 .exe 和一个数据文件，两者必须放在一起。

  4. 在另一台电脑上运行

    它在写入任何内容之前先检查程序包的哈希，然后安装，再读回已安装的内容并进行检查。如果出现任何问题，或者你取消了安装，它会恢复所做的更改，但它安装的运行时除外。它会在“设置”中留下卸载程序。

完整流程，分步说明

安装程序中包含哪些内容

  • 程序文件：通过 MSI 和 Inno Setup 的记录、NSIS 日志、App Paths，以及与产品名称完全一致的文件夹找到。
  • 注册表项：应用适用于整台电脑的注册表项、COM 类、文件类型、链接协议、菜单命令和外壳扩展。
  • 服务和驱动程序、计划任务、快捷方式，以及防火墙规则、字体和保存应用路径的环境变量。
  • 运行时：它需要的 Visual C++ 和新式 .NET 运行时，在生成时下载并放入安装程序中，因此无需联网即可安装；除非当时某个运行时无法下载。
  • 用户数据和许可证数据（如果你选择包含）。它绝不会绕过激活；与旧电脑绑定的许可证可能需要重新激活。
  • 绝不包含凭据。看起来像密码、令牌或私钥的值和文件会被排除，并在你生成之前列出。

包含的全部内容，以及不包含的内容

使用你的语言，人人可用

本应用、它生成的每个安装程序，以及用于旧电脑的客户端，都支持 24 种语言，并首先使用 Windows 当前的语言。安装程序使用其所运行的电脑的语言，而不是生成它的电脑的语言；阿拉伯语、波斯语、乌尔都语和希伯来语采用从右到左的布局。除英语外，其他语言均由机器翻译；如果哪里读起来不对，请告诉我们。

每个控件都可以通过键盘访问，并且有供屏幕阅读器读出的名称；窗口会遵循 Windows 的对比度主题、文本大小和动画效果设置。它们按照 WCAG 2.2 AA 进行检查，一致性报告说明了检查方式。

语言和辅助功能

在依赖它之前

项目每次推送更改时，都会将五个真实的开源应用（7-Zip、PuTTY、Eclipse Mosquitto、windows_exporter 和 Git LFS）从一台测试机迁移到全新的测试机上，并让 Windows 本身使用还原的内容。这些都是在干净的计算机上运行、表现良好的小型应用。这些测试尚未在 x64 上的桌面版 Windows 10 和 11 中运行过；带联机激活的应用、加载驱动程序以及之后重启，则完全没有试过。

因此，在依赖安装程序之前请先试用，并在读取即将损坏的驱动器之前先为它创建映像。它仅适用于你有权迁移的软件。

限制 · 要求和测试

获取

  1. 下载 WinAppMigrator-v${version}.exe，它位于最新版本中。无需安装。
  2. 运行它。Windows 会请求管理员批准，因为读取其他驱动器和安装服务都需要管理员权限。它的签名者为 Randy Northrup。
  3. 选择一个应用，在你单击任何按钮之前，屏幕就会显示其安装程序中将包含的内容。
