# 문제 해결

아래에서 나타난 증상이나 화면에 표시된 문구로 찾아보세요. 따옴표로 묶은 문구는 프로그램에 표시되는 내용이며, 중간에 이름이나 숫자가 들어가기도 합니다.

여기에서 해결되지 않으면 끝에 있는 [도움 받기](#getting-help)를 참조하세요.

<a id="the-window-could-not-open"></a>

## 창을 열 수 없음

**표시되는 내용.** 창 대신 메시지 상자가 표시됩니다.

- 앱: "창을 열 수 없습니다"와 "창을 그리려면 Direct3D 12가 필요합니다. 오래된 그래픽 드라이버나 가상 머신에서는 지원되지 않을 수 있습니다."
- 설치 관리자: 같은 내용과 "창 없이도 설치할 수 있습니다. 관리자 권한 명령 프롬프트에서 이 파일을 --apply 옵션으로 실행하세요. 설치할 위치를 정하려면 --target-root 뒤에 폴더를 지정하세요."
- 제거 프로그램: 같은 내용과 "창 없이도 관리자 권한 명령 프롬프트에서 다음 명령으로 제거할 수 있습니다:", 그리고 입력할 명령

**원인.** 창은 [Direct3D 12](Glossary#direct3d-12)로 그려지며, 그 밖에 창을 그릴 방법이 없습니다.

**해결 방법.**

- PC의 그래픽 드라이버를 업데이트하세요.
- 설치 관리자나 제거 프로그램은 명령줄을 사용하세요. [명령줄](Command-Line)을 참조하세요.
- 앱에는 명령줄이 없습니다. 다른 PC에서 빌드하세요. 이전 PC의 드라이브를 그 PC에 연결할 수 있습니다. [연결된 드라이브에서 옮기기](Moving-from-a-Connected-Drive)를 참조하세요. 그 PC에서 네트워크를 통해 이전 PC를 읽을 수도 있습니다. [네트워크를 통해 PC에서 옮기기](Moving-over-the-Network)를 참조하세요.

| 표시되는 내용 | 해결 방법 |
| --- | --- |
| 드라이브에 대해 "Windows 시스템 드라이브가 아닌 것 같습니다(\Windows 및 \Users 없음). 다른 PC에서 가져온 드라이브의 루트를 선택하세요." | 드라이브 안의 폴더가 아니라 `E:\`처럼 드라이브의 맨 위를 선택하세요. Windows가 설치되어 있던 드라이브인지 확인하세요. |

| 이미지에 대해 "읽을 수 있는 Windows 볼륨이 없습니다. BitLocker로 암호화된 볼륨은 먼저 잠금을 해제해야 합니다." | Windows가 설치되어 있던 드라이브의 이미지인지 확인하세요. [BitLocker](Glossary#bitlocker)로 잠겨 있으면 직접 Windows에 탑재하고 잠금을 해제한 다음, **연결된 드라이브…**에서 그 드라이브를 선택하세요. |
| 이미지에 대해 "차이점 보관용 디스크입니다. 이 디스크에는 부모 디스크를 기준으로 변경된 내용만 들어 있으며" | Hyper-V의 디스크 편집으로 부모 디스크에 병합한 다음 부모 디스크를 선택하세요. |

<a id="reading-a-pc-over-the-network"></a>

### 네트워크를 통해 PC 읽기

클라이언트가 이전 PC에 표시하는 내용을 포함한 전체 목록은 [네트워크를 통해 PC에서 옮기기](Moving-over-the-Network#if-something-goes-wrong)에 있습니다.

| 표시되는 내용 | 해결 방법 |
| --- | --- |
| 이전 PC가 **2. 이전 PC 선택** 아래에 나열되지 않음 | 그 PC에서 클라이언트가 실행 중이며 코드를 표시하고 있는지, 두 PC가 같은 네트워크에 있는지 확인하세요. 그런 다음 그 PC의 이름이나 주소를 입력하세요. 라우터를 거치는 경우에는 주소를 입력하세요. Windows 자체 방화벽이 아닌 다른 방화벽이 있으면 TCP 47732와 UDP 47731을 허용해야 합니다. |
| "네트워크에서" 이름 "을(를) 찾을 수 없습니다" | 대신 이전 PC의 주소를 입력하세요. |
| "이전 PC에 연결할 수 없습니다:"와 이유 | 클라이언트가 아직 실행 중인지, 이름이나 주소가 올바른지 확인하세요. |
| "이전 PC에 표시된 코드가 아닙니다. 확인 후 다시 시도하세요." | 클라이언트에 지금 표시된 코드를 입력하세요. 코드를 5번 잘못 입력하면 새 코드가 만들어집니다. 20번 잘못 입력하면 클라이언트를 다시 시작할 때까지 아무것도 페어링할 수 없습니다. |
| 이전 PC에서 Windows가 클라이언트의 게시자를 알 수 없다고 표시함 | Microsoft의 2020년 루트 인증서가 없어 클라이언트의 서명을 확인할 수 없는 Windows 7에서만 정상입니다. 그런 PC에서는 앱에서 직접 저장한 클라이언트에 대해서만 **예**를 선택하세요. 그 밖의 PC에서는 프롬프트에 Randy Northrup이 표시되어야 합니다. 표시되지 않으면 그 사본을 실행하지 마세요. |
| 오랫동안 사용하지 않은 후 앱에서 이전 PC를 더 이상 읽을 수 없음 | 클라이언트는 앱이 30분 동안 아무것도 요청하지 않은 연결을 끊습니다. **연결 끊기**를 클릭하고 다시 페어링하세요. |

| "남은 항목으로는 패키지를 만들 수 없습니다" | 선택을 취소한 결과 빌드할 수 있는 항목이 남지 않았습니다 | 항목을 다시 선택하세요. |
| "제외한 항목에 있는 라이선스 데이터는 '라이선스 및 정품 인증 데이터' 옵션을 따르므로 그대로 포함됩니다" | 라이선스는 **라이선스 및 정품 인증 데이터** 옵션만 따릅니다 | 라이선스를 제외하려면 그 옵션을 선택 취소하세요. |

### 설치 관리자 만들기 단추가 회색으로 표시됨

다음 조건이 모두 충족될 때까지 기다립니다.

- 현재 옵션에 대한 앱 검사가 끝났습니다("함께 포함될 항목을 확인하는 중…"은 마지막으로 선택을 취소한 항목과 함께 제외될 항목을 아직 확인하고 있다는 뜻입니다).
- **출력 폴더**가 `D:\Installers`처럼 전체 경로입니다("전체 폴더 경로를 입력하세요(예: D:\Installers).").
- 그 드라이브에 공간이 있습니다.

<a id="the-install-location"></a>

### 설치 위치

**설치**와 **변경 내용 미리 보기**가 회색으로 표시되면 **설치 위치** 아래에 빨간색 알림으로 이유가 표시됩니다. 가장 흔한 이유는 웹 브라우저, 미디어 플레이어, Office처럼 그 앱이 이 PC의 해당 폴더에 이미 설치되어 있는 경우입니다. Windows 설정의 **앱**에서 그 사본을 먼저 제거하고 설치 관리자를 다시 열거나, 비어 있는 새 폴더를 입력하세요. 이유와 해결 방법은 [새 PC에 설치](Installing-on-the-New-PC#when-the-location-cannot-be-used)에 나와 있습니다.

<a id="language-and-text"></a>

## 언어 및 텍스트

- **언어가 잘못됨.** 앱이나 설치 관리자 첫 화면의 오른쪽 위에 있는 **언어**에서 다른 언어를 선택하세요. 앱은 선택을 기억하고, 설치 관리자는 그 실행 동안 유지합니다. 아무것도 선택하지 않으면 각각 Windows 표시 언어 중 지원하는 첫 번째 언어를 사용하고, 없으면 영어를 사용합니다.
- **번역이 어색함.** 영어를 제외한 모든 언어는 기계 번역되었습니다. **언어**에서 **번역 문제 보고**를 선택하면 언어가 미리 입력된 양식이 열립니다. 화면에 표시된 내용과 원래 표시되어야 할 내용을 적어 주세요.
- **글자가 빈 상자로 표시됨.** 창은 Windows에 기본으로 들어 있는 각 문자 체계용 글꼴을 `C:\Windows\Fonts`에서 가져와 사용합니다. 그중 일부를 제거한 Windows에서는 해당 글자가 상자로 표시됩니다. 목록에 있는 다른 앱의 이름에도 이런 글꼴이 필요할 수 있습니다.
- **단어가 잘림.** 공간에 맞지 않는 레이블은 `…`로 끝납니다. 마우스를 올리거나 Tab 키로 이동하면 전체 내용을 볼 수 있습니다. 창을 맞게 고칠 수 있도록 언어와 화면을 함께 보고해 주세요.
- **오른쪽에서 왼쪽으로 쓰는 Windows에서 WinAppMigrator Client가 영어로 출력함.** 클라이언트가 실행되는 콘솔에서는 아랍어나 히브리어 글자를 연결하거나 올바른 순서로 표시할 수 없으므로, 영어로 출력하고 그 이유를 알려 줍니다. `--lang`으로 클라이언트가 지원하는 언어를 선택할 수 있습니다.

<a id="getting-help"></a>

## 도움 받기

1. [로그](Glossary#log)를 찾으세요. 실패하면 경로가 **로그**로 표시되며, 명령줄에서는 `Log:`로 출력됩니다. 로그는 `%ProgramData%\WinAppMigrator\logs`에 있습니다. 로그에는 경로와 키 이름이 들어 있으며, 설정, 라이선스 파일, 환경 변수의 내용은 들어 있지 않습니다. 하지만 폴더 이름은 들어 있을 수 있으므로 공유하기 전에 읽어 보세요.
2. 버전, 수행한 작업, 화면에 표시된 내용을 적어 [이슈를 여세요](https://github.com/RandyNorthrup/WinAppMigrator/issues). 앱 완료 화면의 **오류 복사**로 메시지를 복사할 수 있습니다.
3. **이슈에 설치 관리자를 첨부하지 마세요.** 개인 데이터가 들어 있을 수 있습니다.
4. 보안 문제는 대신 [GitHub 보안 권고](https://github.com/RandyNorthrup/WinAppMigrator/security/advisories/new)를 통해 비공개로 보고하세요.
