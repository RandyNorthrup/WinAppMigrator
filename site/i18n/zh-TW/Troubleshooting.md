# 疑難排解

請依照發生的情況或畫面上的文字，在下方找到您看到的內容。引號中的文字是程式顯示的內容，有時中間會夾帶名稱或數字。

如果這裡的內容都沒有幫助，請參閱結尾的[取得協助](#getting-help)。

<a id="the-window-could-not-open"></a>

## 無法開啟視窗

**您看到的內容**。出現訊息方塊，而不是視窗：

- 來自應用程式：「無法開啟視窗」，以及「此程式需要 Direct3D 12 才能繪製視窗，而舊的顯示卡驅動程式或虛擬機器可能不支援。」
- 來自安裝程式：同樣的訊息，以及「仍可在沒有視窗的情況下安裝：請在系統管理員命令提示字元中以 --apply 執行此檔案；若要選擇安裝位置，請加上 --target-root 並在其後指定資料夾。」
- 來自解除安裝程式：同樣的訊息，以及「仍可在沒有視窗的情況下解除安裝，請在系統管理員命令提示字元中執行：」並附上確切的命令。

**原因**。這些視窗是以 [Direct3D 12](Glossary#direct3d-12) 繪製的，沒有其他方式可以繪製。

**處理方式**。

- 更新電腦的顯示卡驅動程式。
- 若是安裝程式或解除安裝程式，請使用命令列。請參閱[命令列](Command-Line)。
- 應用程式沒有命令列。請在另一台電腦上建置：您可以將舊電腦的磁碟機連接到那台電腦。請參閱[從連接的磁碟機移轉](Moving-from-a-Connected-Drive)。那台電腦也可以透過網路讀取舊電腦。請參閱[透過網路從電腦移轉](Moving-over-the-Network)。

<a id="starting-the-app"></a>

## 啟動應用程式

| 您看到的內容 | 意義 | 處理方式 |
| --- | --- | --- |
| UAC 提示顯示應用程式的發行者為「未知的發行者」 | 從 0.5.0 起，應用程式都有簽署。未簽署的應用程式不是發行檔案，或是 0.5.0 之前的版本。 | 從[最新版本](https://github.com/RandyNorthrup/WinAppMigrator/releases/latest)重新下載，並[檢查它](Getting-Started#check-the-download)。 |
| SmartScreen 顯示「Windows 已保護您的電腦」 | SmartScreen 不常看到該檔案 | 選擇**其他資訊**，確認發行者是 Randy Northrup，然後選擇**仍要執行**。 |
| 頂端的標籤顯示**載入失敗**，清單顯示「無法列出應用程式」 | 無法讀取應用程式清單 | 按一下圓形箭頭重新載入。若是連接的磁碟機，請確認它仍然連接著。 |
| 您要的應用程式不在清單中 | 它是 Microsoft Store 應用程式、另一個應用程式的隱藏部分，或者在「設定」中完全沒有項目，例如可攜式應用程式 | Store 應用程式無法移轉。選擇主應用程式時，隱藏的部分可能會列在**可能也屬於它的項目**之下。在「設定」中沒有項目的應用程式無法選擇。 |
| 「沒有相符的應用程式」 | 搜尋或篩選條件隱藏了所有項目 | 清除搜尋方塊，並選擇**全部**。 |

## 建置

<a id="picking-a-drive-or-a-disk-image"></a>

### 選擇磁碟機或磁碟映像

| 您看到的內容 | 處理方式 |
| --- | --- |
| 磁碟機「看起來不像 Windows 系統磁碟機（沒有 \Windows 和 \Users）。請選取來自另一台電腦之磁碟機的根目錄。」 | 選擇磁碟機的最上層，例如 `E:\`，而不是其中的資料夾。確認它是安裝 Windows 的磁碟機。 |
| 映像「不是 Windows 可以掛接的磁碟映像（.vhd 或 .vhdx）」 | 選擇 `.vhd` 或 `.vhdx`。請先將 VMware 或 VirtualBox 磁碟另存為其中一種格式。若是 Hyper-V 檢查點（`.avhdx`），請匯出虛擬機器的磁碟。 |
| 「無法掛接」映像，原因是「Windows 已掛接它，而掛接它的程式可能正在寫入。」 | 它在其他地方已經開啟，例如在檔案總管中掛接。請改為在 **連接的磁碟機…** 下選擇它的磁碟機，或將它取消掛接，然後再選擇一次。 |
| 映像「中沒有可讀取且安裝了 Windows 的磁碟區。以 BitLocker 加密的磁碟區必須先解除鎖定。」 | 確認它是安裝 Windows 之磁碟機的映像。如果它以 [BitLocker](Glossary#bitlocker) 鎖定，請自行在 Windows 中掛接並解除鎖定，然後在 **連接的磁碟機…** 下選擇它的磁碟機。 |
| 映像「是差異磁碟，只包含從其來源磁碟建立以來的變更」 | 使用 Hyper-V 的「編輯磁碟」將它合併到其來源磁碟，然後選擇該磁碟。 |
| 「無法掛接」映像，並附上其他原因 | 這是 Windows 本身提供的原因。請閱讀原因，確認沒有其他程式正在使用該映像，然後再試一次。 |

<a id="reading-a-pc-over-the-network"></a>

### 透過網路讀取電腦

完整清單（包括用戶端在舊電腦上顯示的內容）請參閱[透過網路從電腦移轉](Moving-over-the-Network#if-something-goes-wrong)。

| 您看到的內容 | 處理方式 |
| --- | --- |
| 舊電腦未列在 **2. 選擇舊電腦**之下 | 確認用戶端正在那台電腦上執行並顯示配對碼，而且兩台電腦位於同一個網路上。然後輸入它的名稱或位址。如果中間隔著路由器，請輸入它的位址。Windows 內建防火牆以外的防火牆必須允許 TCP 47732 和 UDP 47731 通過。 |
| 「在網路上找不到」某個名稱 | 改為輸入舊電腦的位址。 |
| 「無法連線到舊電腦：」以及原因 | 確認用戶端仍在執行，而且名稱或位址正確。 |
| 「這不是舊電腦顯示的配對碼。請檢查後再試一次。」 | 輸入用戶端目前顯示的配對碼。輸入錯誤五次後，它會產生新的配對碼。錯誤 20 次後，在您重新啟動它之前，它不會接受任何配對。 |
| 在舊電腦上，Windows 顯示用戶端的發行者為「未知的發行者」 | 只有在沒有 Microsoft 2020 年根憑證的 Windows 7 上才應該如此，因為它無法檢查用戶端的簽章。在那種情況下，只有對您自己從應用程式儲存的用戶端，才選擇**是**。在其他任何地方，提示都應該顯示 Randy Northrup。如果沒有，請不要執行那份複本。 |
| 長時間閒置後，應用程式無法再讀取舊電腦 | 如果應用程式 30 分鐘都沒有向用戶端要求任何內容，用戶端就會結束連線。按一下**中斷連線**，然後重新配對。 |

<a id="looking-at-the-app"></a>

### 檢查應用程式

| 您看到的內容 | 意義 | 處理方式 |
| --- | --- | --- |
| 「無法檢查此應用程式：」以及原因 | 檢查失敗。常見的原因之一是項目完全沒有對應的程式，例如驅動程式套件。 | 按一下**再試一次**。如果以同樣的方式失敗，該項目可能不是 WinAppMigrator 可以移轉的應用程式。 |
| 「已停止。此應用程式檢查完成後，才能建置安裝程式。」 | 您按了**停止** | 按一下**重新檢查**。 |
| 檢查花了很長的時間 | 應用程式很大、磁碟機速度慢或即將故障，或者帳戶很多 | 如果磁碟機可能即將故障，請按一下**停止**，為它建立[磁碟映像](Glossary#disk-image)，然後改為選擇該映像，因為讀取即將故障的磁碟機可能會讓它徹底損壞。從 0.6.0 起，請使用 **磁碟映像…** 選擇它。在 0.5.0 中，請掛接映像並選擇其磁碟機。否則，請等候。在此期間，您可以選擇其他應用程式。 |
| 您要的某一列呈灰色且已勾選 | 它包含主程式，或啟動所需的項目 | 它一律會包含在內。請參閱[無法取消勾選的列](Building-an-Installer#the-groups)。 |
| 某一列顯示「也已排除：」 | 您取消勾選的某個項目連帶排除了它 | 如果您需要這一列，請重新勾選該項目。 |
| 「剩下的內容無法構成套件」 | 您取消勾選的項目使得剩下的內容無法建置 | 重新勾選某些項目。 |
| 「您排除的內容中的授權資料仍會包含在內」 | 授權只依**授權與啟用資料**選項決定 | 如果您要排除授權，請取消勾選該選項。 |

<a id="create-installer-stays-greyed-out"></a>

### 「建立安裝程式」一直呈灰色

它會等到下列條件全部成立：

- 已針對目前的選項完成應用程式的檢查（「正在判斷與其相關的項目…」表示它仍在判斷您上次取消勾選的項目會連帶排除哪些內容）；
- **輸出資料夾**是完整路徑，例如 `D:\Installers`（「請輸入完整的資料夾路徑，例如 D:\Installers。」）；
- 該磁碟機上有足夠的空間。

<a id="room"></a>

### 空間

| 您看到的內容 | 處理方式 |
| --- | --- |
| 「空間不足。」以及某個磁碟機需要多少空間、有多少空間 | 在其他磁碟機上選擇輸出資料夾，或排除部分項目。這個數字是建置在壓縮前可能需要的最大空間，因此可能比安裝程式實際的大小還大。 |
| 磁碟機「未提供其可用空間」 | 建置會繼續進行，但不檢查該磁碟機。請確認它有足夠的空間。 |
| FAT32 磁碟機和大型應用程式 | FAT32 無法存放 4 GiB 的檔案。請使用 NTFS 或 exFAT 磁碟機。 |

<a id="the-done-screen"></a>

### 完成畫面

| 您看到的內容 | 處理方式 |
| --- | --- |
| 「安裝程式已建置，但有」幾個檔案「在檢查應用程式後已不存在」 | 如果這些檔案很重要，請按一下**重新檢查**，然後按一下**再次建立安裝程式**。 |
| 「安裝程式已建置，但有」幾個檔案「無法擷取，通常是因為檔案已鎖定或無法讀取。」 | 關閉應用程式以及其他正在使用其檔案的程式，然後重新建置。**警告**會列出是哪些檔案。 |
| 「安裝程式已建置，但其中仍含有關於其來源的資訊。」 | 閱讀下方的琥珀色訊息。請參閱[最後檢查](Building-an-Installer#the-last-look)。 |
| **警告**顯示「無法下載」某個執行階段，以及「安裝程式會在目標電腦上嘗試使用 winget。」 | 該執行階段不在安裝程式中，因此新電腦需要網際網路才能取得它。請在連線狀態下重新建置。請參閱[執行階段](Runtimes#at-build-time)。 |
| 「請勿使用此安裝程式：它未通過雜湊檢查。」 | 請勿使用。請重新建置。如果再次發生，磁碟機可能即將故障。 |
| 「安裝程式已寫入，但無法執行其雜湊檢查」 | 請勿使用。請重新建置。 |
| 「已取消建置。未寫入任何安裝程式。」 | 您按了**取消**。 |
| 「無法建置安裝程式。」以及原因 | 閱讀原因。**複製錯誤訊息**可以複製它，**記錄檔**會顯示記錄檔的位置。 |
| 「無法建立輸出資料夾」 | 選擇您可以寫入的資料夾。 |
| 「無法建立受保護的暫存資料夾，因此未建置任何內容」 | 建置無法在輸出資料夾旁邊或 Windows 的暫存資料夾中，建立其私人工作資料夾。請在其他磁碟機上選擇輸出資料夾。 |
| 「建置意外停止」 | 發生了預料之外的錯誤。「如果它在輸出資料夾中留下了安裝程式，請勿使用。」請[回報這個問題](#getting-help)。 |

<a id="installing"></a>

## 安裝

<a id="when-the-installer-opens"></a>

### 安裝程式開啟時

| 您看到的內容 | 意義 | 處理方式 |
| --- | --- | --- |
| 「正在檢查安裝程式…」持續很久 | 它會讀取整個套件以檢查其雜湊 | 請等候。大型安裝程式需要一些時間。 |
| 「無法讀取安裝程式：」以及「此安裝程式已損毀，或在建置後遭到變更，因此未從其套件讀取任何內容。請從建置它的位置重新複製。」 | 檔案被截斷或遭到變更 | 重新複製。 |
| 「此安裝程式將其套件存放在同一資料夾中名為」某個 `.wamdata` 檔名「的檔案內，但該檔案不存在」 | 雙檔案安裝程式缺少其資料檔 | 將 `.wamdata` 檔案複製到同一個資料夾。請參閱[大型應用程式](Big-Apps)。 |
| 資料檔「不是此安裝程式的資料檔，或已損毀，或在建置後遭到變更」 | 資料檔不相符 | 從建置它們的位置重新複製這兩個檔案。 |
| 「此安裝程式的套件無法在這台電腦上使用：」以及「此應用程式無法在這台電腦上執行，因此未做任何變更」 | 應用程式的程式是為另一種處理器建置的，或某個程式表示它需要較新的 Windows | 在與舊電腦類似的電腦上安裝。未做任何變更。 |
| 「這是 WinAppMigrator 的安裝程式空殼，不含任何應用程式套件。」 | 這是單純的空殼，而不是建置好的安裝程式 | 使用應用程式建置安裝程式，然後執行該安裝程式。 |
| 「此安裝程式的簽章無效」，並附上 Windows 提供的原因 | 它有簽署，但 Windows 不接受該簽章。它可能在簽署後遭到變更，或者它的憑證在這台電腦上不受信任。 | 請勿安裝。請向建置它的人確認。 |
| UAC 提示顯示「未知的發行者」 | 安裝程式未簽署。您自己建置的安裝程式通常都是如此。 | 只有在您信任其來源時才執行。 |

<a id="the-install-location"></a>

### 安裝位置

當**安裝**和**預覽變更**呈灰色時，**安裝位置**下方的紅色通知會說明原因。最常見的原因是此應用程式已安裝在這台電腦的該資料夾中，網頁瀏覽器、媒體播放程式或 Office 經常如此：請先在 Windows「設定」的**應用程式**中解除安裝該複本，然後重新開啟安裝程式，或輸入新的空白資料夾。各種原因及處理方式，請參閱[在新電腦上安裝](Installing-on-the-New-PC#when-the-location-cannot-be-used)。

<a id="before-or-during-the-install"></a>

### 安裝之前或期間

| 您看到的內容 | 意義 | 處理方式 |
| --- | --- | --- |
| 「這裡的空間可能不足」 | 磁碟機看起來空間不足 | 釋放空間，或選擇其他磁碟機上的位置。 |
| 「空間不足，因此未做任何變更」 | 它要寫入的磁碟機太滿 | 在該處釋放空間，或選擇其他磁碟機上的安裝位置。 |
| 「在這裡要執行的作業已有變更，因此未安裝任何內容。」 | 自計算清單後，電腦上有些內容變更了 | 再次閱讀清單，如果內容符合您的需求，請再按一次**安裝**。 |
| 「先前安裝」某個應用程式「的作業未完成。按『安裝』時會先將它復原。」 | 先前的安裝被中斷 | 按一下**安裝**。它會先復原該安裝。 |
| 「另一個安裝或解除安裝作業正在執行。請等它完成後再試一次」 | 一次只能執行一個 | 請等候，然後再試一次。 |
| 某個檔案「的名稱在此版本的 Windows 中會被當成裝置而非檔案開啟」 | 應用程式有名稱類似 `aux.h` 的檔案，Windows 11 之前的 Windows 無法存放這種檔案 | 在 Windows 11 上安裝。 |
| 「無法建立暫存資料夾」 | 找不到有足夠空間的私人位置來解壓縮套件 | 在安裝位置所在的磁碟機或系統磁碟機上釋放空間。 |
| 訊息指出 `%AppData%` 之類的資料資料夾是連結 | 安裝程式不會透過[連結](Glossary#link)寫入 | 取消勾選**使用者資料**和**授權**，然後在不包含它們的情況下安裝。 |
| 「找不到這台電腦的 ProgramData 資料夾，因此未安裝任何內容」 | 無法讀取 Windows 本身記錄的 ProgramData 位置 | 安裝程式沒有安全的位置可保存其記錄時，就不會進行安裝。 |

<a id="the-result"></a>

### 結果

| 您看到的內容 | 處理方式 |
| --- | --- |
| 「安裝失敗，所做的變更已恢復原狀。」 | 閱讀紅色訊息以了解原因。除了它安裝的執行階段之外，電腦已恢復原狀。 |
| 「安裝失敗，且所做的變更無法全部恢復。」 | 閱讀列出的內容。關閉可能正在使用這些檔案的程式，然後再次執行安裝程式：它會先再試一次。 |
| 「無法安裝」某個執行階段 | 無法安裝該執行階段，因此安裝已恢復原狀。若是 DirectX End-User Runtime，新電腦需要網際網路。請參閱[執行階段](Runtimes#with-no-internet-on-the-new-pc)。 |
| 「有相依元件需要重新啟動才能完成。請重新啟動 Windows，然後啟動應用程式。」 | 重新啟動，然後啟動應用程式。 |
| 服務「在來源電腦上以」某個帳戶「身分執行。其密碼不在安裝程式中，因此服務會設定為以 LocalService 身分執行。」 | 如果服務無法正常運作，請開啟「服務」，設定該服務的帳戶和密碼。 |
| 部分檔案「會改放在」安裝資料夾「下名為 _external 的資料夾中」 | 這台電腦將「文件」或「儲存的遊戲」保存在您的設定檔之外。請自行將這些檔案移到該資料夾。 |
| 某個項目「已排除」，並附有原因 | 規則拒絕了它，或者它在這裡已經屬於其他應用程式。其餘部分都已安裝。如果應用程式需要它，請參閱原因。 |
| **套件雜湊無效**或**已安裝的檔案無效** | 有內容不相符。重新複製安裝程式，然後再試一次。 |

<a id="after-installing"></a>

### 安裝之後

| 您看到的內容 | 處理方式 |
| --- | --- |
| 應用程式無法啟動 | 檢查**相依性**中是否有標示為**手動安裝**的執行階段，並安裝它。檢查結果中的警告。 |
| 來自 Windows 7 的應用程式無法啟動，而建置時的警告指出某個 DLL「Windows 10 和 11 並未內建」 | 該 DLL 是由其他項目放在舊 Windows 本身的資料夾中，因此沒有一併帶過來。請安裝提供它的項目，然後再次啟動應用程式。請參閱[來自 Windows 7、Vista、8 或 8.1 的應用程式](Moving-from-a-Connected-Drive#apps-from-windows-7-vista-8-or-81)。 |
| 應用程式啟動時像是全新的一樣 | 以關閉**使用者資料**的方式建置的安裝程式，這是正常現象。如果安裝時取消勾選了**使用者資料**，也會發生這種情況，因為資料會放在安裝資料夾下；安裝程式無法判斷誰已登入時也會如此，而它會說明這一點。 |
| 應用程式要求啟用 | 綁定舊電腦的授權需要重新啟用。 |
| 應用程式本身的更新程式認為它未安裝 | Windows Installer 在這裡沒有它的記錄。請參閱[限制](Limitations)。 |
| 檔案類型或連結類型無法以此應用程式開啟 | 這裡已有其他應用程式擁有它，因此保持原狀。請在「設定」的「預設應用程式」中選擇此應用程式。 |
| 看不到新的 `Path` 項目 | 開啟新的 PowerShell 或命令提示字元。有些程式要在您登出再登入後，才會看到變更。 |

<a id="uninstalling"></a>

## 解除安裝

| 您看到的內容 | 處理方式 |
| --- | --- |
| 「有部分內容位於未連接的磁碟機上。」 | 連接該磁碟機，然後從「設定」再次解除安裝。 |
| 「無法全部復原。請關閉正在使用它的程式，然後從『設定』再次解除安裝。」 | 關閉應用程式以及任何正在使用其檔案的程式。如果服務無法停止，請重新啟動電腦。然後再次解除安裝。 |
| 「這不是安裝的識別碼」（命令列中為「this is not an install's id」） | 提供給 `--uninstall` 的識別碼錯誤。請從「設定」中的項目複製。請參閱[命令列](Command-Line#finding-the-id)。 |
| 出現名為 `.before-install` 的檔案 | 這是安裝所取代之檔案的原始版本，而您在安裝後曾變更過它。請保留您想要的版本。 |
| 執行階段仍然安裝著 | 執行階段會保留，因為其他程式可能會使用。除非您確定沒有其他程式使用它，否則請保留它。 |

<a id="scripts"></a>

## 指令碼

| 您看到的內容 | 處理方式 |
| --- | --- |
| 「The requested operation requires elevation」，或中文版 Windows 上意思相同的訊息 | 以系統管理員身分執行 PowerShell。 |
| 沒有顯示任何內容，而且未設定 `$LASTEXITCODE` | 將安裝程式的輸出透過管線傳送，例如傳給 `Out-String`。請參閱[命令列](Command-Line)。 |
| 結束代碼 `2` | 有旗標錯誤，或同時使用了 `--apply` 和 `--dry-run`。 |
| 命令列以英文顯示「this package does not say where its app was, so give a --target-root」（此套件未說明其應用程式原本的位置） | 加上 `--target-root` 並指定完整路徑。 |
| 應用程式「was in」某個資料夾，「and that cannot be used」（原本的資料夾無法使用） | 加上 `--target-root` 並指定其他資料夾。 |
| 某個資料夾「cannot be used: it already has files」，以及「Give --force only if you know it is this app's」（資料夾中已有檔案） | 選擇空白資料夾。只有在您確定資料夾屬於此應用程式時，才使用 `--force`。 |

<a id="language-and-text"></a>

## 語言與文字

- **語言不對**。在應用程式或安裝程式第一個畫面右上角的**語言**中，選擇其他語言。應用程式會記住您的選擇；安裝程式只會在該次執行中保留。如果沒有做任何選擇，它們都會使用 Windows 顯示語言中第一個它支援的語言，否則使用英文。
- **翻譯讀起來不對**。除了英文以外，所有語言都是由機器翻譯。在**語言**下選擇**回報翻譯問題**，就會開啟已填入您語言的表單。請說明畫面上顯示的內容，以及應該顯示什麼。
- **文字顯示成空白方塊**。視窗會使用 Windows 為每種文字系統隨附的字型，這些字型位於 `C:\Windows\Fonts`。如果 Windows 移除了其中某些字型，這些字元就會顯示成方塊；清單中其他應用程式的名稱也可能需要這些字型。
- **文字被截斷**。放不下的標籤會以 `…` 結尾；將滑鼠停留在標籤上，或用 Tab 鍵移到標籤上，即可看到完整內容。回報這個問題時請附上語言和畫面，以便調整視窗。
- **WinAppMigrator Client 在由右至左的 Windows 上顯示英文**。它執行所在的主控台無法連接或排列阿拉伯文或希伯來文字母，因此它會顯示英文並說明原因。`--lang` 可以選擇它支援的任何語言。

<a id="getting-help"></a>

## 取得協助

1. 找到[記錄檔](Glossary#log)。失敗時，它的路徑會顯示為**記錄檔**，從命令列執行時則會以 `Log:` 輸出。記錄檔位於 `%ProgramData%\WinAppMigrator\logs`。其中包含路徑和機碼名稱，但絕不包含設定、授權檔案或環境變數的內容。不過其中仍可能包含您的資料夾名稱，因此分享之前請先閱讀。
2. [提出問題](https://github.com/RandyNorthrup/WinAppMigrator/issues)，並附上版本、您做了什麼，以及畫面上顯示的內容。應用程式完成畫面上的**複製錯誤訊息**可以複製訊息。
3. **絕對不要將安裝程式附加到問題中**。它可能包含私人資料。
4. 如果是安全性問題，請改為透過 [GitHub 的安全性公告](https://github.com/RandyNorthrup/WinAppMigrator/security/advisories/new)私下回報。
