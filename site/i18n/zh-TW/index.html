WinAppMigrator

將已安裝的 Windows 程式移轉到新電腦

WinAppMigrator 會將一台 Windows 電腦上已安裝的應用程式轉成一個安裝程式，讓您在另一台電腦上執行。即使應用程式位於網路上的舊 Windows 7 電腦、從即將故障的電腦拆下的磁碟機，或該磁碟機的映像中，而且原始安裝程式早已不見，也一樣可以。

適用的情況

換到新電腦

應用程式會一併移轉，您不必再四處尋找它的安裝檔、授權檔案或設定。

開始使用

舊電腦無法開機

將它的磁碟機拆下，連接到一台正常運作的電腦，然後從其中的應用程式建置安裝程式。如果磁碟機可能即將故障，請先為它建立映像，再從映像建置，因為讀取即將故障的磁碟機可能會讓它徹底損壞。

從磁碟機或磁碟映像移轉

告別 Windows 7、Vista、8 或 8.1

這些系統上的應用程式可以移到 Windows 10 或 11，當時不同的地方也會一併處理：32 位元 Windows、VirtualStore 以及 DirectX 9 執行階段。

來自舊版 Windows 的應用程式

舊電腦仍可運作，而且在您的網路上

在舊電腦上執行小巧且已簽署的 WinAppMigrator Client，輸入它顯示的配對碼，然後選擇應用程式。只有建置所需的內容會經過網路傳輸，而且全程加密。不必從電腦中拆下任何東西。

透過網路從電腦移轉

安裝檔不見了，或公司已經不在了

它會從已安裝的內容反向推導：應用程式的檔案、登錄項目、服務，以及它需要的 Microsoft 執行階段。

運作方式

在多台電腦上安裝相同的應用程式

它建置的安裝程式可以從命令提示字元預覽、安裝和解除安裝，因此可以用指令碼在每台電腦上安裝相同的應用程式。

命令列

運作方式

  1. 選擇應用程式

    來源可以是這台電腦、插在這台電腦上的另一台電腦的磁碟機、應用程式以唯讀方式掛接的 .vhd 或 .vhdx 映像，或您網路上的另一台電腦。

  2. 查看要包含的內容

    畫面會顯示安裝程式可能的大小、是否放得下，以及其中包含的內容。取消勾選您不要的項目，並勾選看起來相關、但名稱比對沒有找到的項目。

  3. 建置安裝程式

    您會得到一個以其內容命名的 .exe。太大而無法放進一個檔案的應用程式，會產生一個 .exe 和一個資料檔，兩者必須放在一起。

  4. 在另一台電腦上執行

    它在寫入任何內容之前，會先檢查套件的雜湊，然後進行安裝，再讀回已安裝的內容並加以檢查。如果發生任何錯誤，或您取消安裝，它會恢復它所做的變更，但它安裝的執行階段除外。它會在「設定」中留下解除安裝程式。

完整流程的逐步說明

安裝程式包含的內容

  • 程式檔案，透過 MSI 和 Inno Setup 記錄、NSIS 記錄檔、App Paths，以及與產品名稱完全相符的資料夾找到。
  • 登錄項目：應用程式適用於整部電腦的機碼、COM 類別、檔案類型、連結通訊協定、功能表命令和殼層擴充功能。
  • 服務和驅動程式、排定的工作、捷徑、防火牆規則、字型，以及存放應用程式路徑的環境變數。
  • 執行階段：它需要的 Visual C++ 和新式 .NET 執行階段，會在您建置時下載並放進安裝程式，因此不需網際網路即可安裝，除非當時有某個執行階段無法下載。
  • 使用者資料和授權資料（如果您選擇包含）。它絕不會規避啟用機制，而綁定舊電腦的授權可能需要重新啟用。
  • 絕不包含認證。看起來像密碼、權杖或私密金鑰的值和檔案會被排除，並在您建置之前列出。

所有包含與不包含的內容

以您的語言，為每個人設計

應用程式、它建置的每個安裝程式，以及用於舊電腦的用戶端，都支援 24 種語言，並且一開始就使用 Windows 的語言。安裝程式使用的是執行它的電腦的語言，而不是建置它的電腦的語言；阿拉伯文、波斯文、烏爾都文和希伯來文會由右至左排列。除了英文以外，所有語言都是由機器翻譯；如果有讀起來不對的地方，請告訴我們。

每個控制項都可以用鍵盤操作，並且有供螢幕助讀程式使用的名稱；視窗也會遵循 Windows 的對比佈景主題、文字大小和動畫效果設定。它們依據 WCAG 2.2 AA 進行檢查，符合性報告說明了檢查的方式。

語言與協助工具

在您依賴它之前

專案每次推送變更時，都會將五個真實的開放原始碼應用程式（7-Zip、PuTTY、Eclipse Mosquitto、windows_exporter 和 Git LFS）從一台測試電腦移轉到全新的電腦，並請 Windows 本身使用還原的內容。這些都是行為良好的小型應用程式，而且是在乾淨的電腦上執行。x64 上的桌面版 Windows 10 和 11 尚未在這些測試中執行過；需要線上啟用的應用程式、載入驅動程式，以及之後重新啟動，則完全還沒有測試過。

因此，在依賴安裝程式之前請先試用，並在讀取即將故障的磁碟機之前，先為它建立映像。它只適用於您有權移轉的軟體。

限制 · 需求與測試

取得 WinAppMigrator

  1. 下載 WinAppMigrator-v${version}.exe，可從最新版本取得。不需要安裝。
  2. 執行它。Windows 會要求系統管理員核准，因為讀取另一個磁碟機和安裝服務都需要這個權限。它的簽章上的名稱是 Randy Northrup。
  3. 選擇應用程式，畫面就會在您按下任何按鈕之前，顯示其安裝程式會包含的內容。
