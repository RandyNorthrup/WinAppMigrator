# トラブルシューティング

起きていることや画面に表示される言葉から、以下で該当するものを探してください。「」で囲まれた言葉はプログラムに表示されるもので、途中に名前や数値が入ることがあります。

ここで解決しない場合は、最後の[サポートを受ける](#getting-help)を参照してください。

<a id="the-window-could-not-open"></a>

## ウィンドウを開けない

**現象**：ウィンドウの代わりにメッセージ ボックスが表示されます。

- アプリの場合：「ウィンドウを開けませんでした」と「ウィンドウの描画には Direct3D 12 が必要です。古いグラフィックス ドライバーや仮想マシンでは使用できない場合があります。」
- インストーラーの場合：同じメッセージと、「ウィンドウがなくてもインストールできます。管理者として実行したコマンド プロンプトから、--apply を付けてこのファイルを実行してください。インストール先を選ぶには、--target-root の後にフォルダーを指定します。」
- アンインストーラーの場合：同じメッセージと、「ウィンドウがなくても、管理者として実行したコマンド プロンプトから次のコマンドでアンインストールできます：」に続く、そのまま使えるコマンド。

**原因**：ウィンドウは [Direct3D 12](Glossary#direct3d-12) で描画されており、ほかに描画する手段はありません。

**対処方法**：

- PC のグラフィックス ドライバーを更新します。
- インストーラーまたはアンインストーラーの場合は、コマンド ラインを使用します。[コマンド ライン](Command-Line)を参照してください。
- アプリにはコマンド ラインがありません。別の PC で作成してください。古い PC のドライブをその PC に接続できます。[接続したドライブからの移行](Moving-from-a-Connected-Drive)を参照してください。その PC からネットワーク経由で古い PC を読み取ることもできます。[ネットワーク経由での PC からの移行](Moving-over-the-Network)を参照してください。

## 作成

<a id="picking-a-drive-or-a-disk-image"></a>

### ドライブまたはディスク イメージの選択

| 表示内容 | 対処方法 |
| --- | --- |
| ドライブ「は Windows のシステム ドライブではないようです（\Windows と \Users がありません）。別の PC のドライブのルートを選択してください。」 | そのドライブ上のフォルダーではなく、`E:\` のようなドライブの最上位を選択します。Windows がインストールされていたドライブであることを確認します。 |
| イメージ「は、Windows でアタッチできるディスク イメージ（.vhd または .vhdx）ではありません」 | `.vhd` または `.vhdx` を選択します。VMware や VirtualBox のディスクは、先にいずれかの形式で保存してください。Hyper-V のチェックポイント（`.avhdx`）の場合は、仮想マシンのディスクをエクスポートします。 |
| イメージ「をアタッチできませんでした：Windows で既にアタッチされており、アタッチしたものが書き込み中である可能性があります。」 | ほかの場所で開かれています。たとえば、エクスプローラーでマウントされています。代わりに **接続したドライブ…** でそのドライブを選択するか、デタッチしてから、もう一度選択します。 |
| イメージ「には、読み取り可能な Windows のボリュームがありません。BitLocker で暗号化されたボリュームは、先にロックを解除する必要があります。」 | Windows がインストールされていたドライブのイメージであることを確認します。[BitLocker](Glossary#bitlocker) でロックされている場合は、自分で Windows にマウントしてロックを解除し、**接続したドライブ…** でそのドライブを選択します。 |
| イメージ「は差分ディスクです。差分ディスクには作成元のディスクからの変更しか含まれず」 | Hyper-V の「ディスクの編集」で作成元のディスクにマージし、そのディスクを選択します。 |
| イメージ「をアタッチできませんでした：」とその他の理由 | 理由は Windows 自身によるものです。理由を読み、ほかにイメージを使用しているものがないことを確認して、もう一度お試しください。 |

<a id="reading-a-pc-over-the-network"></a>

### ネットワーク経由での PC の読み取り

古い PC 上のクライアントに表示される内容を含む完全な一覧は、[ネットワーク経由での PC からの移行](Moving-over-the-Network#if-something-goes-wrong)にあります。

| 表示内容 | 対処方法 |
| --- | --- |
| 古い PC が **2. 古い PC を選択**の下に表示されない | 古い PC でクライアントが実行されていてコードが表示されていること、両方の PC が同じネットワーク上にあることを確認します。その後、古い PC の名前またはアドレスを入力します。ルーターを越える場合は、アドレスを入力します。Windows ファイアウォール以外のファイアウォールでは、TCP 47732 と UDP 47731 の通過を許可する必要があります。 |
| 「ネットワーク上で」名前「が見つかりませんでした」 | 代わりに古い PC のアドレスを入力します。 |
| 「古い PC に接続できませんでした：」と理由 | クライアントがまだ実行されていること、名前またはアドレスが正しいことを確認します。 |
| 「古い PC に表示されているコードと一致しません。確認して、もう一度お試しください。」 | クライアントに現在表示されているコードを入力します。間違ったコードが 5 回入力されると、クライアントは新しいコードを作成します。20 回になると、クライアントを再起動するまでペアリングできなくなります。 |
| 古い PC で、クライアントの発行元が不明であると Windows に表示される | これが想定どおりなのは、Microsoft の 2020 年のルート証明書がない Windows 7 だけです。その環境ではクライアントの署名を確認できません。その場合は、自分でアプリから保存したクライアントの場合にのみ**はい**を選択します。それ以外の環境では、確認画面に Randy Northrup と表示されるはずです。表示されない場合は、そのコピーを実行しないでください。 |
| しばらく操作しなかった後、アプリから古い PC を読み取れなくなった | クライアントは、アプリから 30 分間何も要求されなかった接続を終了します。**切断**をクリックし、もう一度ペアリングします。 |

### アプリを調べる

| 表示内容 | 意味 | 対処方法 |
| --- | --- | --- |
| 「このアプリを調べることができませんでした」と理由 | 調査に失敗しました。よくある理由の 1 つは、ドライバー パッケージのように、プログラムがまったくないエントリです。 | **再試行**をクリックします。同じように失敗する場合、そのエントリは WinAppMigrator で移行できるアプリではない可能性があります。 |
| 「停止しました。このアプリを調べ終えると、インストーラーを作成できます。」 | **停止**をクリックしました | **もう一度調べる**をクリックします。 |
| 調査に時間がかかる | 大きなアプリ、遅いドライブや故障しかけたドライブ、または多数のアカウント | ドライブが故障しかけている可能性がある場合は、**停止**をクリックし、そのドライブの[ディスク イメージ](Glossary#disk-image)を作成して、代わりにそれを選択します。故障しかけたドライブを読み取ると、とどめを刺すおそれがあるためです。0.6.0 以降では、**ディスク イメージ…** で選択します。0.5.0 では、イメージをマウントしてそのドライブを選択します。それ以外の場合は、そのまま待ちます。その間に別のアプリを選択することもできます。 |
| 含めたい行が淡色表示で、チェックが付いている | メイン プログラム、または起動に必要なものが含まれています | 常に含まれます。[チェックを外せない行](Building-an-Installer#the-groups)を参照してください。 |
| 行に「併せて除外：」と表示される | チェックを外した何かと一緒に除外されました | これを含めたい場合は、そのものにもう一度チェックを付けます。 |
| 「残りの内容ではパッケージを作成できません」 | チェックを外した結果、作成できるものが何も残っていません | 何かにもう一度チェックを付けます。 |
| 「除外した内容に含まれるライセンス データは、「ライセンスとライセンス認証のデータ」オプションに従うため、引き続き含まれます」 | ライセンスは**ライセンスとライセンス認証のデータ**オプションにのみ従います | 除外したい場合は、そのオプションのチェックを外します。 |

<a id="create-installer-stays-greyed-out"></a>

### 「インストーラーの作成」が淡色表示のままになる

次のすべてが満たされるまで待機します。

- 現在のオプションで、アプリの調査が完了していること（「それに伴う内容を確認しています…」と表示されている場合は、最後にチェックを外したものと一緒に除外されるものをまだ確認しています）
- **出力フォルダー**が `D:\Installers` のような完全なパスであること（「D:\Installers のように、フォルダーの完全なパスを入力してください。」）
- そのドライブに空き領域があること

<a id="room"></a>

### 空き領域

| 表示内容 | 対処方法 |
| --- | --- |
| 「空き領域が不足しています。」と、ドライブに必要な量と空き領域 | 別のドライブの出力フォルダーを選択するか、何かを除外します。この数値は、作成時に圧縮前の状態で使用される可能性のある最大量のため、実際のインストーラーより大きくなることがあります。 |
| ドライブ「の空き領域を取得できなかったため」 | そのドライブを確認せずに作成が続行されます。空き領域があることを確認してください。 |
| FAT32 ドライブと大きなアプリ | FAT32 には 4 GiB のファイルを保存できません。NTFS または exFAT のドライブを使用します。 |

| 「作成が予期せず停止しました」 | 想定外の問題が発生しました。「出力フォルダーにインストーラーが残っている場合は、使用しないでください。」[報告](#getting-help)をお願いします。 |

| データ ファイル「はこのインストーラーのデータ ファイルではないか、破損しているか、作成後に変更されたため」 | データ ファイルが一致しません | 作成された場所から、両方のファイルをもう一度コピーします。 |

| 「これは WinAppMigrator のインストーラー スタブで、アプリケーション パッケージは含まれていません。」 | これは作成されたインストーラーではなく、スタブ単体です | アプリでインストーラーを作成し、それを実行します。 |

| UAC プロンプトに「不明な発行元」と表示される | インストーラーは署名されていません。自分で作成したものであれば、これは通常のことです。 | 入手元を信頼できる場合にのみ実行してください。 |

<a id="the-install-location"></a>

### インストール先

**インストール**と**変更のプレビュー**が淡色表示の場合は、**インストール先**の下の赤い通知に理由が表示されます。最もよくある理由は、アプリがこの PC のそのフォルダーに既にインストールされていることです。Web ブラウザー、メディア プレーヤー、Office でよくあります。まず Windows の「設定」の**アプリ**でそのコピーをアンインストールしてからインストーラーをもう一度開くか、空の新しいフォルダーを入力してください。理由と対処方法は、[新しい PC へのインストール](Installing-on-the-New-PC#when-the-location-cannot-be-used)にあります。

<a id="the-result"></a>

### 結果

| 表示内容 | 対処方法 |
| --- | --- |
| 「インストールに失敗し、変更は元に戻されました。」 | 赤いメッセージで理由を確認してください。インストールしたランタイムを除き、PC は元の状態に戻っています。 |
| 「インストールに失敗し、変更の一部を元に戻せませんでした。」 | 表示されている内容を確認してください。それらのファイルを使用している可能性があるものを閉じて、インストーラーをもう一度実行します。最初に、元に戻す処理が再試行されます。 |
| ランタイム「をインストールできませんでした」 | ランタイムをインストールできなかったため、インストールは元に戻されました。DirectX End-User Runtime の場合は、新しい PC にインターネット接続が必要です。[ランタイム](Runtimes#with-no-internet-on-the-new-pc)を参照してください。 |
| 「依存関係の処理を完了するには再起動が必要です。Windows を再起動してから、アプリを起動してください。」 | 再起動してから、アプリを起動します。 |
| 「サービス」名前「は、移行元の PC で」アカウント「として実行されていました。パスワードはインストーラーに含まれていないため、サービスは LocalService として設定されます。」 | 現状のままで動作しない場合は、「サービス」を開いて、サービスのアカウントとパスワードを設定します。 |
| 一部のファイルが、代わりにインストール フォルダー「の下の _external という名前のフォルダーに配置されます」 | この PC では、ドキュメントまたは保存したゲームがプロファイルの外に置かれています。それらのファイルを自分でそのフォルダーに移動してください。 |
| 何かが「除外されました」と理由とともに表示される | 規則によって拒否されたか、この PC で既に別のアプリに属しています。それ以外はインストールされています。アプリにそれが必要な場合は、理由を確認してください。 |
| **パッケージのハッシュ：無効**または**インストールされたファイル：無効** | 何かが一致しませんでした。インストーラーをもう一度コピーして、もう一度試してください。 |

<a id="after-installing"></a>

### インストール後

| 表示内容 | 対処方法 |
| --- | --- |
| アプリが起動しない | **依存関係**で**手動でインストール**と表示されているランタイムを確認し、インストールします。結果の警告も確認します。 |
| Windows 7 からのアプリが起動せず、作成時の警告で、DLL が「Windows 10 および 11 には含まれていません」と表示されていた | その DLL は、ほかの何かによって古い Windows 自身のフォルダーに置かれたため、移行されませんでした。それを提供するものをインストールしてから、もう一度アプリを起動します。[Windows 7、Vista、8、8.1 からのアプリ](Moving-from-a-Connected-Drive#apps-from-windows-7-vista-8-or-81)を参照してください。 |
| アプリが新しくインストールしたときのように起動する | **ユーザー データ**をオフにして作成したインストーラーでは、想定どおりです。インストール時に**ユーザー データ**のチェックを外した場合（データがインストール フォルダーの下に配置されるため）や、インストーラーがサインインしているユーザーを判別できなかった場合（その旨が表示されます）にも起こります。 |
| アプリがライセンス認証を求める | 古い PC に関連付けられたライセンスは、再度ライセンス認証が必要です。 |
| アプリ自身の更新機能が、アプリがインストールされていないと判断する | Windows インストーラーには、この PC でのアプリの記録がありません。[制限事項](Limitations)を参照してください。 |
| ファイルの種類またはリンクの種類がアプリで開かない | この PC では既に別のアプリがそれを所有していたため、そのままにされました。「設定」の「既定のアプリ」でアプリを選択します。 |
| 新しい `Path` エントリが認識されない | PowerShell またはコマンド プロンプトを新しく開きます。プログラムによっては、サインアウトしてもう一度サインインするまで変更が認識されません。 |

<a id="uninstalling"></a>

## アンインストール

| 表示内容 | 対処方法 |
| --- | --- |
| 「一部が、接続されていないドライブ上にあります。」 | そのドライブを接続し、「設定」からもう一度アンインストールします。 |
| 「一部を元に戻せませんでした。使用中のものを閉じて、「設定」からもう一度アンインストールしてください。」 | アプリと、そのファイルを使用しているものをすべて閉じます。サービスが停止しない場合は、PC を再起動します。その後、もう一度アンインストールします。 |
| 「これはインストールの ID ではありません」（コマンド ラインでは "this is not an install's id"） | `--uninstall` に指定した ID が間違っています。「設定」のエントリからコピーしてください。[コマンド ライン](Command-Line#finding-the-id)を参照してください。 |
| `.before-install` という名前のファイルが現れた | インストールによって置き換えられたファイルの元のファイルで、その後あなたが変更していたものです。必要な方を残してください。 |
| ランタイムがまだインストールされている | ほかのプログラムが使用している可能性があるため、ランタイムは残ります。ほかに何も使用していないと確信できない限り、そのままにしてください。 |

<a id="scripts"></a>

## スクリプト

| 表示内容 | 対処方法 |
| --- | --- |
| 「要求された操作には管理者特権が必要です」（英語版の Windows では "The requested operation requires elevation"） | PowerShell を管理者として実行します。 |
| 何も表示されず、`$LASTEXITCODE` が設定されない | インストーラーの出力を、たとえば `Out-String` にパイプします。[コマンド ライン](Command-Line)を参照してください。 |
| 終了コード `2` | フラグが間違っているか、`--apply` と `--dry-run` が一緒に使用されました。 |

| アプリがフォルダーに "was in"、"and that cannot be used"（そのフォルダーにありましたが、その場所は使用できません） | 別のフォルダーを指定して `--target-root` を追加します。 |
| フォルダーが "cannot be used: it already has files"、"Give --force only if you know it is this app's"（使用できません：既にファイルがあります。このアプリのものだとわかっている場合にのみ --force を指定してください） | 空のフォルダーを選択します。`--force` は、このアプリのものだとわかっているフォルダーにのみ使用してください。 |

<a id="language-and-text"></a>

## 言語とテキスト

- **言語が違う**：アプリ、またはインストーラーの最初の画面の右上にある**言語**で、別の言語を選択します。アプリは選択を記憶します。インストーラーは、その実行の間だけ選択を保持します。何も選択していない場合は、それぞれ Windows の表示言語のうち対応している最初の言語で表示され、対応している言語がなければ英語で表示されます。
- **翻訳がおかしい**：英語以外はすべて機械翻訳です。**言語**で**翻訳の問題を報告**を選択すると、使用している言語が入力済みのフォームが開きます。画面に表示されている内容と、本来どう表示されるべきかを記入してください。
- **文字が空の四角で表示される**：ウィンドウは、各文字体系について Windows に付属するフォントを `C:\Windows\Fonts` から使用します。一部のフォントが削除された Windows では、それらの文字が四角で表示されます。一覧にあるほかのアプリの名前の表示にも、それらのフォントが必要になることがあります。
- **言葉が途中で切れる**：収まらないラベルは `…` で終わります。マウス ポインターを合わせるか、Tab キーで移動すると、全体が表示されます。ウィンドウを修正して収まるようにできるよう、言語と画面を添えて報告してください。
- **右から左に書く言語の Windows で、WinAppMigrator Client が英語で表示される**：クライアントが実行されるコンソールでは、アラビア語やヘブライ語の文字を連結したり正しい順序に並べたりできないため、英語で表示し、その理由も表示します。`--lang` で、クライアントが対応している任意の言語を選択できます。

<a id="getting-help"></a>

## サポートを受ける

1. [ログ](Glossary#log)を見つけます。失敗した場合はそのパスが**ログ**として表示され、コマンド ラインからは `Log:` として出力されます。ログは `%ProgramData%\WinAppMigrator\logs` にあります。ログにはパスとキー名が含まれますが、設定、ライセンス ファイル、環境変数の内容が含まれることはありません。ただし、フォルダー名が含まれることがあるため、共有する前に内容を確認してください。
2. バージョン、行った操作、画面に表示された内容を添えて、[Issue を作成](https://github.com/RandyNorthrup/WinAppMigrator/issues)します。アプリの完了画面の**エラーのコピー**で、メッセージをコピーできます。
3. **Issue にインストーラーを添付しないでください。** 個人データが含まれている可能性があります。
4. セキュリティ上の問題は、代わりに [GitHub のセキュリティ アドバイザリ](https://github.com/RandyNorthrup/WinAppMigrator/security/advisories/new)から非公開で報告してください。
