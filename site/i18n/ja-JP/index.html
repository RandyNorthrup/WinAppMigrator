インストールされている Windows プログラムを新しい PC に移行

WinAppMigrator は、ある Windows PC にインストールされているアプリを、別の PC で実行できる 1 つのインストーラーにします。アプリがネットワーク上の古い Windows 7 PC にある場合も、故障しかけたコンピューターから取り外したドライブやそのイメージにある場合も、元のインストーラーがとうになくなっていても使えます。

役立つ場面

新しい PC への移行

セットアップ ファイル、ライセンス ファイル、設定を探し回らなくても、アプリを移行できます。

はじめに

古い PC が起動しない

ドライブを取り外して正常に動作する PC に接続し、そこにあるアプリからインストーラーを作成します。ドライブが故障しかけている可能性がある場合は、先にそのイメージを作成し、イメージから作成してください。故障しかけたドライブを読み取ると、とどめを刺すおそれがあるためです。

ドライブまたはディスク イメージから

Windows 7、Vista、8、8.1 からの移行

これらの Windows のアプリを Windows 10 または 11 に移行できます。32 ビット Windows、VirtualStore、DirectX 9 ランタイムなど、古い Windows で異なっていた点にも対応します。

古い Windows のアプリ

古い PC がネットワーク上でまだ動作している

古い PC で署名済みの小さな WinAppMigrator Client を実行し、表示されたコードを入力して、アプリを選択します。ネットワークを経由するのは作成に必要なものだけで、暗号化されます。PC から何かを取り外す必要はありません。

ネットワーク経由で PC から

セットアップ ファイルがない、または開発元がもうない

インストールされているものから逆にたどります。アプリのファイル、レジストリ エントリ、サービス、アプリに必要な Microsoft のランタイムです。

しくみ

同じアプリを複数の PC に

作成したインストーラーは、コマンド プロンプトからプレビュー、インストール、アンインストールができるため、スクリプトで各 PC に同じアプリをインストールできます。

コマンド ライン

しくみ

  1. アプリを選択

    この PC、この PC に接続した別の PC のドライブ、アプリが読み取り専用でアタッチする .vhd または .vhdx イメージ、またはネットワーク上の別の PC から選択します。

  2. 含まれる内容を確認

    インストーラーの最大サイズ、収まるかどうか、含まれる内容が画面に表示されます。不要なもののチェックを外し、名前の完全一致では見つからなかった関連のありそうなものにチェックを付けます。

  3. インストーラーを作成

    含まれる内容にちなんだ名前の .exe が 1 つ作成されます。1 つに収まらない大きなアプリの場合は、.exe と、それと一緒に置いておくデータ ファイルになります。

  4. 別の PC で実行

    何かを書き込む前にパッケージのハッシュを確認してからインストールし、インストールした内容を読み戻して確認します。問題が発生した場合やキャンセルした場合は、インストールしたランタイムを除き、行った変更を元に戻します。「設定」にアンインストーラーが残ります。

全体の流れを順を追って説明

インストーラーに含まれるもの

  • プログラム ファイル：MSI と Inno Setup の記録、NSIS のログ、App Paths、製品名と完全に一致する名前のフォルダーから見つけます。
  • レジストリ エントリ：アプリの PC 全体のキー、COM クラス、ファイルの種類、リンク プロトコル、メニュー コマンド、シェル拡張です。
  • サービスとドライバー、スケジュールされたタスク、ショートカット、ファイアウォール規則、フォント、アプリのパスを保持する環境変数。
  • ランタイム：アプリに必要な Visual C++ ランタイムと最新の .NET ランタイムです。作成時にダウンロードして中に入れるため、インターネットなしでインストールできます。ただし、作成時にダウンロードできなかったものは除きます。
  • ユーザー データとライセンス データ（選択した場合）。ライセンス認証を回避することはありません。古い PC に関連付けられたライセンスは、再度ライセンス認証が必要になる場合があります。
  • 資格情報は含めません。パスワード、トークン、秘密キーのように見える値やファイルは除外され、作成前に表示されます。

含まれるもの、含まれないもののすべて

あなたの言語で、すべての人に

アプリ、アプリが作成するすべてのインストーラー、古い PC 用のクライアントは 24 の言語に対応しており、最初は Windows の言語で表示されます。インストーラーは、作成された PC ではなく、実行される PC の言語で表示されます。アラビア語、ペルシア語、ウルドゥー語、ヘブライ語は右から左にレイアウトされます。英語以外はすべて機械翻訳です。おかしな箇所があれば、お知らせください。

すべてのコントロールはキーボードで操作でき、スクリーン リーダー用の名前が付いています。ウィンドウは Windows のコントラスト テーマ、テキストのサイズ、アニメーション効果に従います。WCAG 2.2 AA に照らして確認されており、その方法は適合性レポートに記載されています。

言語とアクセシビリティ

使用する前に

プロジェクトへのプッシュのたびに、実際のオープンソース アプリ 5 つ（7-Zip、PuTTY、Eclipse Mosquitto、windows_exporter、Git LFS）を 1 台のテスト マシンから新しいマシンに移行し、復元したものを Windows 自体に使わせて確認しています。これらは、クリーンなマシン上の、小さく素直なアプリです。デスクトップ版の Windows 10 および 11（x64）はこれらのテストで実行されておらず、オンライン ライセンス認証のあるアプリ、ドライバーの読み込み、その後の再起動はまったく試されていません。

そのため、インストーラーは使用する前に試してください。また、故障しかけたドライブは、読み取る前にイメージを作成してください。移行が許可されているソフトウェアにのみ使用してください。

入手方法

  1. WinAppMigrator-v${version}.exe を最新リリースからダウンロードします。インストールは不要です。
  2. 実行します。別のドライブの読み取りとサービスのインストールにはどちらも管理者の承認が必要なため、Windows が承認を求めます。署名には Randy Northrup の名前が表示されます。
  3. アプリを選択すると、何かをクリックする前に、そのインストーラーに含まれる内容が画面に表示されます。
